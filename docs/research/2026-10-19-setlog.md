# Setlog はなぜ広まったか／Kinda に何を取り入れるか（2026-10-19）

> ふうかさんの問い：Setlog が有名になったのは「ほとんど何もしなくても共有できる」手軽さでは？ Kinda にも取り入れたら面白そう。
> **結論：いまは新しく作らない。空の手帳に戻ってくる人がいるかを 11月上旬まで見てから決める**（2026-10-19 ふうか合意）。
> 集客の論点メモ `docs/research/2026-10-14-shuukyaku-nagare.md` の続きとして読む。

## 1. Setlog とは

- 韓国発のアプリ。2025年12月に出た。日本では 2026年春ごろから学生の間で広まった
- 1時間ごとに通知が来て、2秒の動画を撮るだけ。加工やフィルターはできない
- **撮らなかった時間は黒い枠として残るだけ。** 撮影は必須ではない
- 投稿は友達グループ（最大20人）にだけ届く。1日分をつなげると1本の Vlog のように見える。カレンダーで見返せる

## 2. 広まった理由（重要な順）

1. **友達に誘われないと価値が出ない設計。** 使い始めたきっかけの 70.9% が「友達に誘われた」。TikTok は 15.9%、Instagram/X は 10.4%（学生479人の調査）。ひとりでは楽しくないので、使う人が自分で誘う
2. **撮らなくていい。** 魅力の1位は「通知に追われず自分のペースで記録できる」35.3%。BeReal は「2分以内に撮れ」と急かす
3. **自分は2秒撮るだけで、仕上げはアプリがやる。** 魅力の2位は「友達と1本の Vlog を作れる共有感」24.1%。3位は「カレンダーで振り返りやすい」15.7%
4. **きっかけは K-pop。** 韓国では SEVENTEEN や aespa のカリナが投稿して火がついた。2026年5月だけで200万ダウンロードを超えた

弱点もある。半数（51.0%）が「一時的な流行で終わる」と答えている。韓国では「1時間ごとの共有は親しい友達同士でも疲れる」「見張り合いのようだ」という声も出ている。

> 調査の数字は学割アプリ内のアンケート（2026-07-14〜28・479名・女性が約86%）。偏りがある前提で読む。

## 3. Kinda に当てはめると

### 手軽さの部分は、空の手帳にもうある

| Setlog | 空の手帳（2026-10-15 公開） |
|---|---|
| 2秒撮るだけ | 気持ちを3つ押すだけ |
| アプリが1本の Vlog に仕上げる | アプリが天気と街を返す |
| カレンダーで見返す | 行った街がスタンプでたまる。まだの街は「？」 |
| 撮らなかった時間は黒い枠 | 連続日数・皆勤を出さない |

Kinda に無いのは「友達とつながる仕組み」だけ。そしてここがいちばん合いにくい。

### 友達と共有する部分は合いにくい

- Setlog で共有しているのは**いま何をしているかの景色**で、気持ちではない。**気分は友達と共有しない**（ふうかさんの指摘）
- 好きな人・婚活のことは、もともと友達に見せにくい。なので「友達に誘われる」の回り方は Kinda では起きにくい
- 1時間ごとの通知は「焦らせない」（CLAUDE.md §3）に反する
- デート相手との共有にすると、並行が標準の相談所の交際で見張り合いになる

### 検討して外した案

| 案 | 外した理由 |
|---|---|
| 天気を友達グループで見せ合う（最初の Claude 案） | 気分は友達と共有しない。Setlog ほど気軽にならない |
| 空の手帳をまるごと友達に見せる | まだ行っていない街の答えが先に分かってつまらない（ふうかさん） |

### 試すなら：今日の街を1枚だけ画像にしてストーリーズに出す

- 出るのは街の名前と絵だけで、気持ちは出ない
- 見た人に分かるのは1つの街だけなので、残り23の街の楽しみは残る
- 友達グループもサーバーも要らない。today の結果画面にある天気の保存画像（`src/app/kinda-note/components/ShareCard.tsx`）を街の版にするだけ。半日くらいの作業

## 4. 進め方（2026-10-19 ふうか合意）

1. **いまは何も作らない。** 空の手帳は公開して4日目。いま優先するのは1社目の契約と営業
2. **11月上旬に、`/kinda-note/sky` に戻ってくる人がいるかを見る**（Claude が Vercel の数字で確認）
3. 戻ってくる人がいる → 「今日の街を1枚出す」を小さく足す
4. 戻ってこない → 共有を足しても伸びない。手帳そのものを直すほうが先
