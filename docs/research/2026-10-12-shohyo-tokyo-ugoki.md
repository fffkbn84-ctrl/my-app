## 3. ホテラバ LP のような「動き」

参考：https://hotellovers.jp/hlcateb1ocm0001 （ホテラバ × カラコン）

### 中身（HTML を取って確認）

GSAP 3.12.5 ＋ ScrollTrigger ＋ ScrollToPlugin（＋ jQuery）。特別な技術ではない。主な演出：

| 演出 | 仕組み |
|---|---|
| 文字が下からスッと出る | 親を `overflow:hidden` にし、中身を `y:100%→0` |
| キャラが画面端から斜めに入る | `x:-140%, y:60% → 0`（左下から）／`x:110%, y:75% → 0`（右下から） |
| ゆらゆら浮く・左右に揺れる | `y:-5〜-10` や `rotation:±8` を yoyo で無限ループ |
| ビヨンと弾んで出る | `scale:0→1`、`elastic.out` |
| スクロールで奥行き | `scrub` で要素ごとに移動量を変える（パララックス） |
| 震える・オープニング | ランダム振動／最初にスクロールを止めてコマ送り＋ホワイトアウト |

### Kinda に取り入れるなら（トーン §3「焦らせない・穏やか」に合わせる）

- ◎ **見出しの文字がゆっくり下から出る**（0.8〜1秒・`power2.out` 相当の柔らかい減速）
- ◎ **ことさんが画面下からそっと顔を出す**（弾ませない。ゆっくり止まる）
  - ⚠️ 2026-10-14 訂正：ことさんは**クレイではなくフェルトの巾着ぬいぐるみ**（正は `docs/sns/series/kotosan-poses.md`「クレイにしない」）。
    クレイ風のサイトに置いて浮かないか・IG の毒キャラをサイト本体に出してよいかは**未決（ふうか判断）**
- ○ クレイ小物がほんの少し上下に浮く。スクロールで少し奥行き
- × **入れない**：震える・弾む（elastic）・スクロールを止めるオープニング。急かす印象になり、LCP も悪化する

### 実装方針（次セッションで決めること）

- GSAP を入れずに **CSS ＋ IntersectionObserver** で足りる見込み（依存を増やさない）。足りなければ GSAP を検討
- `prefers-reduced-motion` の人には動かさない
- **ヒーロー画像（LCP 要素）は動かさない**。`priority` もそのまま
- キャラは**背景透過のクレイ画像**が新しく要る（ChatGPT で生成 → WebP）
- **フロントのデザイン変更なので CLAUDE.md §7-4 により着手前にふうか確認**。まず1か所だけ試作 → Vercel プレビューで見てもらう
- どのページのどこに入れるかは未定（候補：トップのヒーロー見出し、`/kinda-pair` LP、`/kinda-note`）

### 次セッションの始め方

ふうかさんが言う言葉：

## 4. Kinda pair の序盤を「楽しく」する（80億分の1 を参考に・2026-10-14）

ふうか所感：**「Kinda pair 序盤に文字多すぎ。見るの楽しくない」**。参考 https://1in8b.life/ja/

### 80億分の1 の中身（HTML を取って・開いてからの数秒を撮って確認）

- 1枚の HTML（約4MB・データ埋め込み）＋ canvas ＋ requestAnimationFrame の自前実装。**ライブラリなし**
- 「読み込み演出」ではない。楽しさの正体は3つ：
  1. **開いた瞬間から数字が動く**（「このページを開いてから生まれた赤ちゃん」1→2→4→9→19 と数秒で増える）
  2. **地図の点が灯る**（いまどこで生まれたかが点で出る）＋「たった今・誰かがインドで生まれました」の1行
  3. **説明は4行だけ・ボタンは1つ（「生まれる」）**。あとは押して体験させる
- 数字は国連統計からの**推計**（実際の訪問者数ではない）

### Kinda pair に持ち込むときの線

- ✕ **「いま◯人が並べています」のような数字は作らない。** pair v1.0 は fetch しない・DB を持たない（CLAUDE.md §5）ため実数がない。
  それっぽい数字を出すと「やらせ排除」という信頼の核に触れる
- ◎ **28の話題を点（4層×7）で並べ、開いたら順に灯す**（数字を作らずに「動いている」感じを出す。点＝話題なので嘘がない）
- ◎ **1枚だけ触れるカード**：LP の上のほうで話題カードを1枚めくれる（3択は押せるが保存しない or そのまま solo に続く）
- ◎ **本文を畳む**：「会話が続かないのは…」の3段落を1〜2行に。詳しくは開閉 or `/topics` へ
- 点数・％・相性・「診断」は使わない（§5 pair 細則）。絵文字なし、状態は色と細い SVG

  箇条書きなど、もっと分かりやすい形にしたい → 3段落を「あるある3つ（短い行）＋ pair がすること1行」に組み替える案から

## 5. note today の天気を「世界のどこかの空」に置く（2026-10-14 ふうか案の掘り下げ）

### ふうかさんの考え（2026-10-14）

- 80億分の1 の楽しさは**自分の知らない人生を歩んだ気になれる**ところ
- 世界地図に自分の1回の天気を置くのも同じこと。**嘘ではなく「その経験をした気持ち」になる・コレクションしたくなる** → ファンがつく。カウンセラー探しだけのサイトではなくなる
- 「その場所の本当の天気と違う＝嘘」は狭くない？

### Claude の訂正（前回の線引きが狭かった）

前回は「置き場所を作り物にするのは不可」と書いた。**これは言い過ぎだった。**
守るべき線は「作り話をしない」ではなく「**作り話を事実のふりで出さない**」。

| 出してよい | 出さない |
|---|---|
| 作り話だと分かる遊び（「あなたの今日の空を世界のどこかに置いてみる」） | 実在の人の今を装う文（「いまリスボンの誰かもあなたと同じ気持ちです」） |
| 実データに基づく一致（「いまダブリンは本当に小雨です」） | 実数のふりをした数字（「いま◯人が記録中」） |
| 統計に基づくフィクション（80億分の1 はこれ） | 口コミ・体験談の作り話 |

80億分の1 自体が「人生シミュレーション」と名乗った作り話で、それで信頼を失っていない。Kinda も**遊びだと分かる形**なら同じことができる。

### 80億分の1 は記録をどう持っているか（HTML を取って確認・2026-10-14）

- **ログインなし。記録はすべて localStorage**（`one8b.lives.v1`＝前世の記録・`one8b.keep.v1`＝覚えておく瞬間 など十数キー）
- 画面にはっきり書いている：「ログインなしで記録をこのブラウザにだけ残します」「この端末にだけ保存されます」
- **消える場面を先に教えている**
  - 「Safari は このサイトに7日以上立ち寄らないと記録を消すことがあります」（iOS の仕様）
  - 「{アプリ}の中で開いた画面は Safari・Chrome とは記録が別々です」（**IG・X のアプリ内ブラウザ**）
  - 「ホーム画面アプリは Safari とは記録を別に保管します」
- **「記録を移す」**：移行コード（英小文字と数字の9文字・3日有効・1回きり）を作り、別のブラウザで入れると記録が加わる。サーバは中継で一時的に持つだけ
- **みんなに見せるものだけサーバへ**：「みんなの人生」（投稿・1時間の上限あり）と「追悼館」（メモリアル・ろうそく）。匿名のセッションIDと、消すためのトークンを端末に持つ
- 自分で書いた一言は「この端末にだけ残り どこにも送られません」
- 有料の「思い出パス」：動画・アルバムを作れる。アカウントは作らず**支払いのメールアドレスで端末に開く**（メールは保存しないと明記）。○日以内は理由を聞かず返金
- 「クラスコード」：同じ4桁を入れた人は同じ赤ちゃんとして生まれる（授業用）

#### Kinda への示唆（すぐ効くもの）

- **IG のリンクから来たゲストは、IG のアプリ内ブラウザに記録が残る。** あとで Safari で開くと「これまでの天気」が空になる。bio の1本目が note today なので、いま実際に起きているはず
- note today には今この注意書きがない。80億分の1 と同じく**結果画面に1行**（「この記録はこのブラウザにだけ残ります。続けて残すならログインか、Safari で開いてください」）を足すのが安い一手
- Kinda はログインがあるので「移行コード」は要らない。ログインが「記録を移す」を兼ねる

### 案（面白さとブレの両面から）

**A. 空の旅（いちばん推す）**
今日の天気が出たら「**いま本当にその空の街**」を1つ見せる。例：小雨 →「いまダブリンは小雨です」。
- 内なる天気と外の本当の天気が一致する。作り話がゼロで、それでも知らない街に連れていかれる
- 一言だけ添える：「ダブリンの朝7時。小雨。」（現地時刻・天気・街。ここまでは事実）
- 実データが要る：世界の数十都市の現在天気を1時間ごとに取る。**無料 API は商用不可のものが多い**（Open-Meteo は商用は有料プラン）。**料金がかかるので着手前に止まって確認する（§7-10）**
- 24種の天気を現実の天気に当てるのは無理がある（「天使の梯子」「迷い雲」など）。現実の天気6〜8種に寄せて対応表を作る

**B. 空のスタンプ帳（コレクション）**
A で訪れた街が端末に溜まる。「あなたの空が行った街」を地図か切手帳で並べる。
- 80億分の1 の「前世の記録」と同じ。毎日開く理由になる
- ✕ **連続日数・皆勤は出さない**（焦らせない §3）。来なかった日を責めない。溜まるだけ
- 24種の天気そのものを集める図鑑もできるが、**集めたくて答えを選ぶ**ようになると note の意味が崩れる。集めるのは「街」のほうが安全

**C. この空の下の、ある一日（知らない人生）**
街ごとに Kinda が書いた短い情景を1文。「ダブリン。小雨。パン屋の前で傘をたたむ人がいます。」
- 80億分の1 の「知らない人生」にいちばん近い。ただし**作り話だと分かる書き方**にする（「〜かもしれません」or 情景として書く。実在の誰かの気持ちにしない）
- 書く量が多い（20都市×7天気＝140文）。始めるなら12都市から

**D. 地図にランダムで置く（ふうか原案そのまま）**
実データを使わず、世界のどこかにランダムで点を置く。
- 実装は一番軽い・お金もかからない

### 設計：D＋B＋C（v0 案・Claude）

ふうかさんの見立てどおり **「D で街を選び、C の一言で意味を持たせ、B で溜める」** の三段にする。

**1. 街は「ランダム」ではなく「その天気が似合う街」から選ぶ（D を少しだけ賢く）**
- 天気ごとに候補の街を2〜3つ持ち、その中からランダムに1つ
- 例：小雨 → ダブリン／ベルゲン／金沢　朝もや → サンフランシスコ／霧の多い港町　凪 → リスボン／瀬戸内
- 「なぜこの街か」に気候の筋が通るので、2回目以降も「次はどこだろう」が残る

**2. 一言は「情景」として書く（C）。実在の誰かの気持ちにはしない**
- 書き方の型：「街名。天気。そこにある小さな情景1つ」
- 例（たたき台）
  - 「ダブリン。小雨。パン屋の軒先で傘をたたむ音がします。」
  - 「リスボン。凪。坂の上から港の水面がほとんど動いていないのが見えます。」
  - 「金沢。小雨。用水の音が少しだけ大きくなる日です。」
- ✕ 「いまダブリンで誰かがあなたと同じ気持ちです」（事実のふり）
- ✕ 実在の時刻・実在の天気だと読める書き方（A をやらない間は「いま」を使わない）
- 量：v0 は **24天気×2都市＝48文**。都市は使い回して20都市前後

**3. 溜める（B）＝「空の手帳」**
- 結果画面に「今日の空はダブリンへ」＋一言
- 手帳ページ：行った街がスタンプ（街名・天気の色・日付）で並ぶ。**まだ行っていない街は薄い枠だけ**見せる（集めたくなる）
- 出す数字は「行った街の数」の実数だけ。**連続日数・皆勤・ランキングは出さない**（焦らせない）
- 地図は v1 以降。v0 はスタンプの並びだけ（クレイ風の地図を作るのは画像の手間が大きい）

**4. 保存は今の仕組みに乗せる**
- note today はすでに端末の履歴（`kinda_note_history`）に毎回1件ずつ残している。その1件に**街のキーを足すだけ**で手帳はそこから作れる。新しい保存先・サーバは要らない
- ログイン中のマイページ同期（`diagnosis_results`）に街を載せるかは実装時に確認する（載らなくても v0 は成り立つ）
- 文言（街名・一言）は1ファイルに置き、保存するのは街のキーだけ（pair の `topics.ts` と同じ考え方）

**5. 気をつけること**
- 集めたくて答えを選ばないよう、**街は天気から決まり、天気は答えから決まる**ことを崩さない（街を選ばせない）
- 世界の街だけにしない。日本の街も混ぜる（遠すぎると自分ごとにならない。近い街は「行ってみようかな」になる）
- 手帳に「好きな人と行きたい街」などの導線をつけるなら Kinda act とつながる（v1 以降の候補）

### OpenWeatherMap の規約（2026-10-15 調べ）

- 公式の料金ページ（full-price）では無料枠も ODbL で「Commercial use is allowed」。条件は**天気を出す画面に見える形で「Weather data © OpenWeather」**と書くこと（規約ページの奥だけでは不可）
- ただし同社の説明資料（License explainer 2025-02）は無料枠を CC BY-SA（ShareAlike あり）としていて、公式資料どうしで食い違う。使うなら Terms 本文を読んでから
- → **A は不要になった**（下のふうか決定）ので、いまは使わない

### ふうかさんの決定（2026-10-15）＝ v0 の正

1. **D＋C＋B で進める**
2. **まだ行っていない街は「ある」ことだけ見せて、どこかは伏せる**（集めたくなる）
3. **「いまその街の誰か」を書いてよい**。そういうゲーム・そういうコレクションとして面白いほうを取る。観光スタンプのように溜まるのが嬉しい
   - → 前回の「実在の人の今を装わない」の線は**この遊びの中では外す**。守るのは「口コミ・数字・相談所のことを作らない」ほう（表の右列の2・3行目）
   - 手帳ページに「街の様子は Kinda が書いた小さな物語です」を1行だけ置く（遊びだと分かる形。重くしない）
4. 一言は「ダブリン。小雨。」のような**「。」で区切る書き方をしない**。ふつうの文で書く
5. 良いことばかりにしない。**失敗も書く**（降らないと思っていたらどしゃ降り、など）
6. **A（本当の空）は不要**
7. 連続日数なしに賛成

### v1 の設計（2026-10-15 Claude 案・ふうか確認待ち）

- 行っていない街は**地図に出さない**（点の位置で「どの辺か」が分かると、決定2「どこかは伏せる」が崩れる）。数だけ「まだ 17 の街があります」
