### 返金ポリシー（送客手数料）｜2026-10-16 改定・現行モデル

送客手数料は**予約成立（即時課金）をもって確定し、原則として返金しません**。「キャンセル」＝面談を取りやめること、「日程変更」＝面談を別日程に振り替えることをいいます。

| ケース | 取り扱い |
|---|---|
| 予約確定 | 即時 ¥5,500（税込）を相談所の登録カードに課金（猶予期間なし） |
| 以後のキャンセル・当日キャンセル・ユーザーの面談不参加（無断不参加を含む） | **返金なし・課金確定** |
| 日程変更（ユーザー・相談所いずれの申出でも） | **返金なし・課金確定** |
| 天災その他やむを得ない事情 | 運営事務局へ相談 → 運営が認めた場合は、返金に代えて**次回以降の送客手数料1件分に充当**（可否は運営が決定・充当に期限なし） |
| 充当前に解約した場合 | 未充当の分を返金。原則は決済に用いたクレジットカードへの返金。できない場合は掲載事業者名義の銀行口座へ振込（振込手数料は当社負担） |

- 充当の対象となった決済にチャージバック（カード会社への異議）が申し立てられた場合、未使用の充当は取り消します。
- カードへの返金が明細に反映されるまでの日数は、カード会社によって異なります（数日〜10日ほど）。
