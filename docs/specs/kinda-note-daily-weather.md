# Kinda note 今日の天気（毎日モード）：案（2026-10-03）

> きっかけ：第2段階の実装時、ふうかさん「デイリーで言葉にできない気持ちを天気にするサービスとして、私なら使いたいかもしれない」。
> 状態：**たたき台（未着手）。** §5 を決めてから文案を詰める。第1段階の「これまでの天気」「今日、ひとつだけ」と、IG「note を使ってみた」につながる。

## 1. いまの note との違い

| | いまの note | 今日の天気（案） |
|---|---|---|
| 聞くこと | いまの段階（始める前／会っている）と、その悩み | **今日の気分**。段階は聞かない |
| かかる時間 | 60秒・4〜5問 | **20秒・3問**（＋任意の一言） |
| 使う頻度 | 一度やると完結しがち | **毎日**。「これまでの天気」が日記になる |
| 結果 | 天気＋説明＋カウンセラー向けメモ | 天気のカード＋短い一文＋今日、ひとつだけ |

- 「関係を築いている最中」の人の、今日の気持ち。好きな人のことでも、自分のことでもいい
- 天気は**気分の名前**として出す。良い・悪いの判定や点数にしない。前日と比べて「良くなった」と書かない（ブランドトーン「比較しない」）

## 2. 質問（たたき台）

**Q1 今日、いちばん長くそばにあった気持ちは？**（1つ）
- ほっとしていた
- そわそわしていた
- もやもやしていた
- しんとしていた
- ざわざわして落ち着かなかった
- よくわからない

**Q2 それは、誰のこと？**（1つ）
- 気になっている人のこと
- 自分のこと
- まわりの人のこと
- とくに理由はない

**Q3 いま、ほしいのは？**（1つ）
- 誰かに聞いてほしい
- ひとりの時間
- 少し背中を押してほしい
- このままでいい

**一言**（任意）：今日のことを、ひとことだけ。

- 言葉にできない人のための質問なので、**選択肢は気分の語（ほっと／そわそわ／もやもや）で書く**。天気そのものを選ばせない（天気は「言葉にしてもらった結果」として受け取る）
- 婚活語彙・性別を前提にする語を使わない

## 3. 天気の決め方（たたき台）

Q1 で空の様子、Q3 で光の向きを決める。例：

| Q1 | 天気の候補 |
|---|---|
| ほっとしていた | 晴れ間／薄日 |
| そわそわしていた | 淡い朝焼け／風の強い晴れ |
| もやもやしていた | 霧／花曇り |
| しんとしていた | 静かな曇り／夜明け前 |
| ざわざわして落ち着かなかった | 風の日／雨雲 |
| よくわからない | 朝もや／迷い雲 |

- 候補のどちらにするかは Q3（「誰かに聞いてほしい」「背中を押してほしい」は光のある方）
- **いまある20の天気とカード画像をそのまま使う。** 説明文だけ毎日モード用に短く書く（いまの説明は段階ごとの悩みに寄っているため）

## 4. 置き場所と記録

- `/kinda-note` の入口に「**今日の天気だけ（20秒）**」を、いまの note と並べて置く
- 記録は端末のみ（`localStorage`）。いまの「これまでの天気」に同じ形で積む。サーバーに送らない
- 計測：`kinda_note_daily_complete`（天気名のみ。回答内容は送らない）
