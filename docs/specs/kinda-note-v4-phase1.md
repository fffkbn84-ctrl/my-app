# Kinda note 改修 第1段階：結果画面（案・2026-10-03）

> 方向は `docs/ops/content-plan-2026-10.md` §5（ふうか了承済み）。この文書は第1段階の具体案。
> **質問とタイプ判定は変えない。** 変えるのは結果画面の並びと、足す要素だけ。
> 状態：**実装済み（2026-10-03・ふうか了承）**。了承時の変更：
> - **週ではなく毎日**（ふうか：「今日の天気」日記のように）。「今週、ひとつだけ」→「**今日、ひとつだけ**」、
>   「前回の天気」1行 →「**これまでの天気**」（日付＋天気名を最大6件、新しい順）
> - 小雨の「担当の人」を外した（相談所の担当がいる前提になるため）。同じ理由で雨雲も直した
> - 「話せる人」に頼る3本（小雨・雨雲・雷雨）に「身近にいなければ、カウンセラーに〜のもひとつ」を添えた。
>   話せる人がいない読み手が落ち込まないように（ふうか）

## 0. 現状の確認（訂正を含む）

- 結果画面の一番上には、すでに**天気のポラロイドカードが主役で出ている**。
  10/3 の分析で「結果がメモとして設計されている」と書いたのは言い過ぎだった
- 実際の課題は次の4つ
  1. **シェアが最下部で「最も控えめ」**（コード上もそう明記されている）。画像を保存するボタンは活動中ルートにしかない
  2. **読んだあとにやることがない。** 文章は「いまの状態の説明」で終わっている
  3. **前回の天気が見えない。** 履歴は端末に保存しているのに、どこにも出していない
  4. 入会前ルートのボタンに **Kinda glow** が残っている（glow は A 案で店舗一覧を閉じる）

- Kinda story の誘導カード（明るい3タイプ）はそのまま

### 「前回の天気」の書き方

> 前回（9月28日）は「朝もや」でした。

- **矢印や「良くなった」「悪くなった」は付けない。** 天気は変わるもの、として並べるだけ（ブランドトーン「比較しない」）
- 同じ天気でも同じ書き方にする。「変わっていない」とは書かない
- 履歴がない（初回）ときは出さない

## 2. 「今週、ひとつだけ」20本（案）

条件：実際にできる小さな行動を1つだけ書く／急かさない／相手の性別を前提にしない／絵文字なし／「婚活」「結婚」の語を使わない（診断ページは中立語彙）

| 天気 | 今週、ひとつだけ |
|---|---|
| 朝もや | 気になっていることを3つ書き出して、そのうち1つだけ調べてみる。 |
| 夜明け前 | 一緒に過ごしたい人を、条件ではなく場面で1つ書いてみる。たとえば、休みの朝に何をしているか。 |
| 花曇り | 決めなくていいので、話を聞いてみたい場所を1つだけ選んでおく。 |
| 降り始め | 自分のプロフィールを、友だちに紹介するつもりで声に出して読んでみる。 |
| 小雨 | いま引っかかっていることを1行にまとめて、話せる人に送ってみる。身近にいなければ、カウンセラーに話してみるのもひとつ。 |
| 雨雲 | 「このままでいいのか」を、誰かに口に出して聞いてみる日を決める。身近にいなければ、カウンセラーに聞いてみるのもひとつ。 |
| 雷雨 | 今日は一人で考えるのをやめる。話せる人に、いまの状況をそのまま伝える。身近にいなければ、カウンセラーに話してみるのもひとつ。 |
| 晴れ間 | 次に会うとき、聞いてみたいことを1つだけメモしておく。 |
| 天使の梯子 | 「もう一度会うか」ではなく、「もう一度会ったら何を確かめたいか」を書いてみる。 |
| 風の日 | 「違う」と感じた理由を一言だけ残しておく。次に会う人を選ぶときの手がかりになる。 |
| 淡い朝焼け | 相手が楽しそうだった瞬間を1つ思い出して、次の行き先を選ぶ手がかりにする。 |
| 迷い雲 | もう一度会うなら、前回と違う種類の場所を選んでみる。カフェだったなら、少し歩ける場所に。 |
| 冷たい風 | 違和感を覚えた場面を1つ書き残す。相手を責めるためではなく、自分の基準を知るために。 |
| 朝焼け | これからふたりで決めたいことを1つ、言葉にしておく。 |
| 違和感の風 | ぎこちなかった場面を1つ選んで、そのとき自分が何を感じていたかを書く。 |
| 静かな曇り | 今日は予定を1つ減らして、その時間を自分のために使う。 |
| 霧 | 答えを急がず、次に会う日だけを決めておく。 |
| 夕暮れ | それぞれの人と会ったあとの「帰り道の気分」を、一言ずつ書いて並べてみる。 |
| 風の強い晴れ | 誰とどう過ごしたいかを、ひとりずつ場面で1つ書いてみる。 |
| 薄日 | 頭の中にあることを全部書き出して、今日考えるのは1つだけにする。 |

- 迷い雲・淡い朝焼けは Kinda act へ、朝焼けは Kinda pair へ、一言リンクを添える案もある（第1段階では入れず、反応を見てから）
