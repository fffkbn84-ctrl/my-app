## 【】の埋め方（ここで差がつく）

テンプレート部分は誰に送っても同じなので、読まれるかどうかは共感パートで決まる。
「サイトを拝見しました、素敵でした」だけだとテンプレートだと分かる。
**どの一節を読んでどう思ったかまで書く。** 送る前に相手のサイトで探すのは次の3つ。

- ブログや「私について」にある、**なぜこの仕事をしているか**の話
- 料金ページや FAQ に出る**姿勢**（無理に勧めない、断り方を教える、など）
- 会員さんへの言葉づかいで、**Kinda のトーンと重なるところ**

## 送る前のチェック

- [ ] 【】が全部埋まっているか（1つでも残っていたら送らない）
- [ ] **予約枠（`slots`）に空きがあるか**。相手は必ずサイトを触る。枠が切れていると
      予約導線が動かない。counselor 管理画面のカレンダーから補充する
- [ ] 費用の話を書いていないか
- [ ] 具体的な人数を書いていないか

## メールで送る場合の追加（フォームには不要）

フォーム送信は特定電子メール法の対象外だが、**メールで営業する場合**は
送信者の名称・住所と受信拒否の連絡先を本文に表示する義務がある。
相手が自社サイトにアドレスを公開している事業者であれば事前同意なしに送れるが、
この表示は省略できない。メール版の末尾には次を付ける。

```
--
Kinda（カインダ）
小山楓華
株式会社AGOGLIFE
〒104-0061 東京都中央区銀座1-12
hello@kinda.jp
※今後このようなご案内が不要な場合は、その旨このメールにご返信ください。
```

## 書かないと決めたこと（理由つき）

- **「日本初」「唯一」などの最上級**。客観的な裏付けがないと景表法上の優良誤認に
  なりうる。相手は同業なので「本当に初めてか」とも読まれる。
  言いたいことは「相談所ではなく、カウンセラー個人を選ぶ作りにした」で足りる
- **掲載カウンセラー数・口コミ数などの具体的な数字**。実数が小さいうちは書かない。
  `/about` に実態のない数字（247名・1,840件）を出していたのを 2026-10-06 に撤去した
  のと同じ理由
