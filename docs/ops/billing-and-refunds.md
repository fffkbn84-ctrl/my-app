# 送客料の課金と返金 — 運営の手引き（ふうかさん用）

> 2026-10-13 作成。本番で ¥5,500 を1件課金 → 返金 → キャンセルまで通して確認した結果をもとにしている。
> 決まりごとの正は契約書 `docs/contracts/agency-agreement.md` 第6条と、counselor 管理画面の利用規約 第6条。
> このファイルは「実際に何が起きるか・ふうかさんは何をするか」をまとめたもの。

---

## 1. 課金の流れ（何もしなくても自動で動く）

| 順番 | 起きること | 誰が |
|---|---|---|
| 1 | 相談所が counselor 管理画面 /billing でカードを1回登録する | 相談所 |
| 2 | 利用者が kinda.jp でカウンセラーの枠を予約し、確定する | 利用者 |
| 3 | その場で相談所のカードに **¥5,500（税込）** を課金する | 自動 |
| 4 | Stripe から Kinda に「支払い成功」の通知（Webhook）が届く | 自動 |
| 5 | 予約が「支払い済み」になり、相談所に利用者の連絡先が見えるようになる | 自動 |
| 6 | 利用者に「ご予約が確定しました」、相談所に「新しいご予約が入りました」のメール | 自動 |

- **カード登録は最初の1回だけ。** 予約のたびに入力する必要はない。登録したカードを Kinda が予約ごとに使う（`off_session` 課金）。
- 日程変更では**課金しない**（同じ予約のまま日時だけ変わる）。新しい予約のときだけ課金する。
- Stripe の「Link」は、支払う人が自分のカードを Stripe 側に保存して、別のお店でも使い回すための機能。
  Kinda はカードを相談所ごとに Stripe の「顧客」に保存しているので、**Link がなくても毎回の登録は不要**。
  2026-10-13 にふうかさんが「設定 → 決済手段」でオフにした（カード登録画面にメール欄が出て怪しく見えたため）。

## 2. 返金の流れ

返金は**原則しない**（予約確定で確定。キャンセル・当日キャンセル・不参加・日程変更でも返金なし）。
やむを得ない事情があって運営が認めたときは、**返金ではなく次の予約の送客料1件分に充てる**（2026-10-16 改定。期限なし）。
カードへ返金するのは、**充てる前に相談所が解約したとき**だけ。設計と理由は `docs/ops/refund-credit-slide-2026-10.md`。

### 充当するときの手順（ふうかさん）

> **2026-10-17 に仕組みを作った**（DB：migration 048・049／課金：`/api/stripe/charge`／counselor の /billing）。
> Stripe の「顧客残高（credit）」は請求書（Invoicing）専用で、予約ごとに直接課金する Kinda では使えない。
> そのため Kinda の DB（`agency_credits`）に「未使用の充当」を持ち、次の予約で**課金そのものを止める**。相談所の明細には何も出ない。
> 「いつもどおり課金して返金する」つなぎは**やらない**（2026-10-16 ふうか指摘）。

1. 認めると決めたら、Claude に「予約 yyyy の分を充当にする。理由は〇〇」と伝える
   - Claude が `select grant_agency_credit('予約ID', '理由');` で1件作る（理由は /billing の画面には出さないが、相談所の持ち主は読める列なので、相談所に見られて困ることは書かない）
   - 充当で確定した予約にさらに例外を認めた場合も同じ。**元（お金を払った予約と課金）は自動で引き継ぐ**（日程変更をはさんでも辿る）
2. 相談所の /billing に「次のご予約に充てる分：1件」と出る
3. 次の予約が確定したとき、課金の手前で充当を使う。**カードへの課金は起きない**。
   連絡先の開示・確定メール・請求の記録はカードのときと同じように出る（相談所宛のメールは「充当分を1件使いました（今回の課金はありません）」）。
   /billing ではその予約が「充当で確定（課金なし）」になり、請求額の合計から外れる
4. **相談所が解約したら**（問い合わせで受ける。契約書 第13条・通知から30日で効力）、Claude に「相談所 xxx の未使用の充当」を聞く。
   残っていれば元の課金（`source_payment_intent_id`）を Stripe ダッシュボードで返金する（下の手順）。返したら Claude に伝える（`status='refunded'`・`refund_method='card'` を記録）
5. **カードへの返金が失敗したら** hello@kinda.jp に「【要対応】カードへの返金ができませんでした」が届く（Stripe の `refund.failed`）。
   相談所名義の口座を聞いて振り込む（振込手数料は Kinda 負担）。済んだら Claude に伝える（`refund_method='bank'`）
6. **元の課金にチャージバックが来たら**、その課金から生まれた未使用の充当は自動で取り消す（`status='revoked'`）。チャージバックの要対応メールに件数が出る

### カードへ返金するときの手順（ふうかさん）

1. Stripe ダッシュボード → 取引 → 該当の ¥5,500 を開く（説明欄に `Kinda 送客料 (予約 xxxxxxxx…)` と予約IDが入っている）
2. 「返金」→ 理由を選んで実行
3. **それ以外はしなくてよい。** Stripe からの通知で、Kinda 側の予約に返金の記録が自動で入り、請求の記録も「無効」になる
4. 念のため Claude に「予約 xxxx を返金した」と伝えれば、DB に記録されたか確認する

### お金はどう動くか

- **返金は Stripe から、相談所が登録したカードへ直接戻る。** Kinda が別に振り込むことはない（二重の手間も日数もない）。
- 相談所のカードの明細に出るまで **5〜10日**（Stripe の表示。カード会社によって変わる）。
  実測：2026-10-13 に返金 → 10-16 にカードへ戻った（3日）。人によって差があるので、相談所には「数日〜10日ほど」と伝える。
  すでに請求が締まっていれば、翌月以降の明細でマイナスとして相殺されることもある。
- **Stripe の手数料（¥5,500 につき ¥218＝決済手数料 ¥198＋消費税 ¥20）は返金しても戻らない。** Kinda の負担になる。
- 返金した分は Stripe の残高から引かれる。残高が足りないとマイナスになり、**次の売上から自動で差し引かれる**。
  （2026-10-13 のテスト後の残高は -¥218。次の ¥5,500 の売上の入金が ¥5,282 − ¥218 = ¥5,064 になって解消する）
- **登録口座（三井住友銀行）から勝手に引き落とされることはない。** Stripe がマイナス残高を口座から自動で引き落とせるのは
  米国・カナダ・欧州・豪州・NZ だけで、日本は対象外（2026-10-13 に Stripe 公式ドキュメントで確認）。
  売上がないまま長くマイナスが続いた場合は、Stripe からメールで連絡が来て、こちらから振り込む（残高に入金する）形になる。
  何日で連絡が来るかは公開されていない。法人口座の残高がゼロでも、すぐ困ることはない。
- **返金は取り消せない。** カードへの返金は実行した時点で完了するので、「やっぱり課金のままに戻す」操作はない。
  戻したいときは**新しく ¥5,500 を課金し直す**しかない（手数料 ¥218 がもう一度かかる。相談所の明細には返金と新しい課金の両方が出るので、先に相談所に伝える）。
  いまは運営から課金し直す仕組みがない（§4 の①）ため、そうなったら Claude に頼む。返金ボタンは押す前に予約IDを確かめる。

### 返金の日数を相談所に伝えているか

- 2026-10-16 から、事業者向け特商法に「数日〜10日ほど（カード会社によって異なる）」と書いた。counselor 管理画面の FAQ にも入れる。
- 契約書・counselor 利用規約には日数を書かない（カード会社の事情で変わるため）。

## 3. うまくいかなかったとき

| 起きたこと | 何が起きるか | ふうかさんがすること |
|---|---|---|
| 相談所のカードが未登録・期限切れ・限度額・認証が必要などで課金できない | 予約は成立するが、連絡先は開示されず確定メールも出ない。**hello@kinda.jp に「【要対応】送客料の課金ができませんでした」が届く**（予約ID・相談所・理由） | 相談所にカードの登録・更新を頼む → Claude に伝える（下の「まだ無いもの」①） |
| 相談所がカード会社に「身に覚えがない」と申し立てる（チャージバック） | Stripe からメールが来る。**hello@kinda.jp にも【要対応】メールが届く**。¥5,500 と手数料 ¥1,500 がいったん残高から引かれる | Stripe ダッシュボードで証拠（予約の記録・規約）を出す。Claude に相談 |
| 予約後に利用者がキャンセル | 返金はしない（予約は「キャンセル」、枠は空きに戻る） | なし |

## 5. Claude に頼めること

相談所が登録してきた後も、次のことは Claude がこのチャットから直接確認できる（Stripe・Supabase・Resend・Vercel に接続済み）。

- 相談所のカードが登録されたか（Stripe に顧客とカードがあるか）
- 予約ごとの課金が成功したか、連絡先が開示されたか、メールが届いたか
- 返金が Kinda 側に記録されたか
- 予約枠の補充、課金失敗のときの原因調べ

**Claude にできないこと：** Stripe での返金（2026-10-13 に試して権限なしで拒否された）や Stripe ダッシュボードの設定変更。これらはふうかさんにお願いする。
