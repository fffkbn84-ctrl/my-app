## 1. 診断（ここを間違えると打ち手を外す）

**リーチは取れている。** 非フォロワーに毎回100人前後届いている。配信面の問題ではない。
失敗しているのは次の2点だけ。

1. **1秒で飛ばされている。** 8割が3秒以内に離脱。冒頭で「自分に関係がある」と伝わっていない。
2. **フォローする理由が無い。** 良い単発を見ても人はフォローしない。フォローは「次も来ると分かった」ときに起きる。

そして最大の構造的誤りがこれ。

> **いまの投稿は「Kinda の世界観」を伝えようとしている。しかし視聴者は Kinda を知らない。**
> 世界観は、知っている人にしか効かない。知らない人に効くのは「これは自分のことだ」と1秒で分かることだけ。

W27 のデータがこれを裏づけている。世界観リール（柱A）はリーチ100でプロフ遷移0。
唯一行動を起こしたのは「なぜ Kinda を作ったのか」＝**中身と作り手の話**だった。

## 2. 戦略：3層に役割を分ける（1投稿に2つ以上の役割を持たせない）

| 層 | 役割 | 形式 | 1枚目／1秒目に置くもの |
|---|---|---|---|
| **入口** | 非フォロワーに届く | リール | 相手の**状況の言葉**（世界観ではない） |
| **理由** | フォローされる | 連載カルーセル | 今週の話題の**問いそのもの** |
| **深さ** | プロフィールに来る | つくる日記カルーセル | 作り手の**判断や失敗** |

いま全部の投稿が「入口」を狙って世界観を出し、結果どれも役割を果たしていない。分ける。

## 3. 週の型（固定・週3本。ひとり運用の上限）

| 曜日 | 形式 | 層 | 内容 |
|---|---|---|---|
| **火 20:00** | カルーセル5枚 | 理由 | 連載「ふたりの話題、ひとつずつ」（28話題／`docs/sns/series/kinda-pair-28.md`） |
| **木 20:00** | カルーセル4〜6枚 | 深さ | つくる日記。作るときに迷ったこと・やめたこと |
| **土 12:00** | リール15〜25秒 | 入口 | 火曜の話題を、状況の言葉で開くリール |

**曜日・時間・見た目を動かさない。** 内容より先にリズムが認知される。
量を増やすのは、3秒視聴継続率が30%を超えてから。維持率が直らないうちに本数を増やすのは消耗するだけ。

## 4. 1秒目のルール（最優先の改善点）

冒頭に置いていいものと、置いてはいけないものを決める。

**置く（相手の状況）**
- 「連絡って、こまめな方が安心ですか？」
- 「お見合いの1時間、何を話しますか」
- 「返事が遅いと、気持ちが薄いんだと思ってしまう」

**置かない（こちらの世界観）**
- 風景だけのカット、詩的な一行、ブランド名、ロゴ
- 「〜な夜に。」で始まる情緒的な導入 ← スキップ率92%の実物

判定基準はひとつ。**その1文を読んだ人が「これは自分のことだ」と思うか。** 思わないなら入口には使えない。
世界観は2枚目以降・2秒目以降に置く。捨てるのではなく、順番を変えるだけ。

Kinda pair 28話題の `ask`（`src/lib/pair/topics.ts`）は、**そのまま1秒目に使える形で既に28本ある**。
新しく考えなくていい。

## 5. 語りの文法：説明しない、観察する

参考にしたのは「ハピハピの森」（@hapi2_no_mori）の投稿タイトル。毎回まったく同じ文型で書かれている。

> 【一語のタイトル】＋【誰】は【対象】が 気になるみたいだね

説明しない。評価しない。オチもない。ただ見ているだけ。
これは CLAUDE.md §11 の「**励まさない・断言しない・現象描写にとどめる**」と同じ文法である。

ここから読み直せること：**ポエムと観察は違う。** ポエムは書き手の感情を出す。観察は対象を出す。
どちらも静かだが、スキップ率92%だったのは前者。Kinda はコラムでは現象描写を守れていて、SNSでは情緒に寄っていた。

実装ルール：
- カルーセルの2〜4枚目は、断定を1つ減らす（「〜です」→「〜みたいです」「〜のことが多いです」）
- 文型を毎回固定する。書き分けない。連載であることが文の形で伝わる
- 評価語を置かない（「素敵」「大事」「すごい」）

**採らないもの：**「ホイッピ＆ラッピ」の「ねじれを笑う」構図（愛が重い側と受け流す側）。
発明としては見事だが、Kinda の読者はまさにその関係の中で悩んでいる人であり、
戯画化すると当事者を笑う形になる。CLAUDE.md「侮辱的に読まれうる表現を避ける」に触れる。

### ハッシュタグ（2026-09-12 追記）

**1投稿あたり5個まで。** それ以上は入らない。枠が少ないので、次の型で組む。

| 枠 | 役割 | 例 |
|---|---|---|
| 1〜2 | 顕在ワード（固定） | `#結婚相談所` `#婚活` |
| 3〜4 | その投稿の内容に一致するもの | `#お見合い` `#仮交際` `#結婚準備` |

  フォローされても結婚相談所を探さない。フォロワー0の段階でコンバートしない層が混ざると、
  その人たちが婚活の投稿に反応しないぶんエンゲージメント率が下がり、配信が鈍る。
  残りの枠は回遊タグで婚活側に返す

## 11. 判断待ち（ふうか決裁が要る）

**繰り返し登場する「顔」を作るか。**

ただし SNS 用とはいえ、繰り返し出る存在はいずれブランドの顔になるため、
CLAUDE.md §4「フロントサイトのデザインを勝手に変更・改善しない」の範囲と判断した。**着手前に決裁が要る。**

- 採用する場合：名前を付けるか／天気との関係／クレイ像（ふうか像）との住み分け、を先に決める

## 13. 2026年のアルゴリズム調査（2026-09-23）

> **出典について。** 検索結果の要約から取った。このセッションのネットワーク制限で
> `camtsuku.com` `megdai.jp` `note.com` の本文を開けなかったため、**一次情報を直接確認していない**。
> 複数の日本語記事が同じことを言っている点で確度は高いが、**重み付けの倍率などの数値は又聞き**として扱う。

### 分かったこと

1. **最重要シグナルは「Sends per Reach」＝リーチあたりのDM送信率。**
   Mosseri／Meta の見解として、全面共通の3シグナルは **Watch Time / Likes per Reach / Sends per Reach**。
   このうち送信が、**非フォロワーへの拡散（Unconnected Reach）を決める**。
   いいねより 3〜5倍重いという業界分析がある（数値は又聞き）
2. **保存の時代は終わった。** これまで保存数が重視されてきたが、2026年は送信が最重要に移った。
   **個人消費（保存）より社会的共有（送信）**が評価軸になった
3. **シェアされやすいのは「あるある系」「比較系」「意外な事実」「後で使えるノウハウ」**
4. **尺は二極化。** 15秒以内の短尺 か 60秒以上の長尺。エンタメ系は15秒以内が推奨
5. **非オリジナルはレコメンド対象外**。このルールが写真・カルーセルを含む全フォーマットに拡大された
6. **オーセンティシティ。** AI時代は「作られた感」に敏感で、完璧な投稿より
   **"ちょっと不完全なリアル"**が好まれる

### Kinda にとっての意味

- **ことさんは「あるある系」のど真ん中。方向は合っている**
- **ことさんの 12.15 秒は15秒以内に収まっている。** 短尺側の適正内。
  9/23 に「13秒は長い」を取り下げたのは結果的に正しかったが、**短くする必要もない**
- **クレイのオリジナル画像は強い。** 非オリジナル排除のルールに一切触れない
- **オーセンティシティは要注意。** ことさんの絵は完璧に整っている。
  クレイの指紋・ヘラ跡・手作りの歪みは**まさに"不完全さ"**なので、ここを潰さない

### 送信を取るための核心（2026-09-23 の仮説）

**「これ私じゃん」と「これ○○さんじゃん」は別物。**

DM で送るとき、人は**自分の話ではなく、相手に見せたい話**を送る。

| 反応 | 起きること |
|---|---|
| 自分に当てはまる | いいね・保存 |
| **誰かを思い出す** | **送信** |

ことさんの本音は一人称で「私」の話＝共感＝いいね寄り。
**送信を取りたいなら「あの人に見せたい」が起きる作りが要る。**

判定の材料として、テスト6本を次の軸で見る。

| 回 | 誰かを思い出させるか |
|---|---|
| #1 それ、さっき私が言いました | **強い**（上司を思い出す） |
| #2 金曜17:55 の「ちょっといい？」 | **強い**（上司を思い出す） |
| #3 美容院「このあとお出かけ？」 | 弱い（自分の話で閉じる） |
| #4 口コミを読んでいて | 弱い |
| #5 「今度ご飯行こうよ」 | **強い**（あの友人を思い出す） |
| #6 「まだ結婚しないの？」 | **強い**（親戚を思い出す） |

10/16 の判定で、**この軸と送信数が相関するかを見る**。相関したら、以降は
「誰かを思い出させる回」に寄せる。

### ちいかわ（弱い存在）について

人気の理由として挙がっていたもの。

- 弱さ・泣き虫と、健気な努力家の同居。**守ってあげたくなる**
- 愛くるしい絵の裏に、**理不尽でディストピア的な現実**
- **言葉数が少なく、表情とアクションで伝える**。翻訳を経ずに伝わる
- 「短く消費・長く蓄積」

**ことさんは、いま弱くない。** 設定書§3 は「仕事はできる。真面目で責任感が強い。観察眼が鋭く、
ツッコミが的確」。**意図的に有能に作ってある。**「守ってあげたくなる」は無く、
むしろ**賢い人が余裕で毒を吐いている**とも読める。

弱さを足すなら、**飲み込んだあとに何が起きるか**を見せる方向がある。
いまは飲み込んで、ふくらんで、終わり。**ふくらんだ体が元に戻らない／だんだん歩きにくくなる**
といった蓄積があると、弱さと健気さが出る。ちいかわの「理不尽な現実」とも噛み合う。

**ただしこれは設定書§3 の性格定義に触れる変更。** 10/16 の判定とセットで、
ふうか決裁が要る。テスト期間中はやらない。

### 「不憫かわいい」の系譜（2026-09-23 調査）

ふうかさんの指摘で 可哀想に！ 氏のキャラも調べた。出典は検索結果の要約（本文は egress 制限で開けず）。

| | 形式 | 中身 |
|---|---|---|
| **おぱんちゅうさぎ** | 2コマ漫画・X 発（2022-01） | 「なかなか恵まれない。今にも泣きそうだが、ひたむきに健気に生きていく」 |
| **んぽちゃむ** | **ごく短い動画**（YouTube 主流） | ヨーグルトの妖精。体の大きさを自由に変えられる。語尾「ちゃむ」 |

- **「不憫かわいい」が Z 世代のキーワード**になっている。おぱんちゅうさぎがその代表格
- ヒット要因は**「見た目の可愛さに反したシビア（不憫）な世界観」＝ギャップ**
- んぽちゃむの短編動画のバズ要素は「掛け合い・**意味のない展開**・あるあるネタ・なんか笑える」

### 4つを並べて見えること

| | 絵 | 中身 |
|---|---|---|
| ちいかわ | かわいい | 理不尽・ディストピア |
| おぱんちゅうさぎ | かわいい | 報われない・健気 |
| んぽちゃむ | かわいい | シビア・意味のない展開 |
| ハピハピの森 | かわいい | 辛辣なナレーション |
| **ことさん** | かわいい | **辛辣な本音** |

**ことさんはすでにこの系譜にいる。** かわいい絵 × 中身のギャップという構造は同じ。

**足りないのは「報われなさ」。**

### ①-2 1枚リールの次の候補：間取り・インテリア（2026-09-23 夜・ふうか提案）

> ふうかさん：「人の家の中を見るのが好き。間取りとか面白くないですか？ インテリア（リビングだけ）もアリ？」

**賛成。夜の窓と同じ「覗きたい」を、別の角度から取れる。** 間取りはそれ自体に見る人が多いジャンル（間取り図を眺める趣味・ルームツアー）で、

| 案 | 1枚の中身 | 問い | 送る動機 | 判断 |
|---|---|---|---|---|
| **A. 同じ間取り、4つの暮らし** | 同じ 1LDK を真上から見たクレイの模型を 2×2 で4つ。家具の置き方だけ違う（机が離れている／ソファ1つを分け合う／本であふれている／ほとんど何もない） | 「住むなら、どの部屋？」 | 「これ私たち」「あなたは絶対これ」と相手や友達に | **いちばん筋がいい。** 並べて選ぶ型が夜の窓と同じで、判定もしない |

- 間取り図は**文字を描かせない**（「LDK」「6畳」などは崩れる）。必要ならスクリプトで載せるが、基本は文字なしの模型で見せる
- 絵はクレイの模型。夜の窓と並べたときに同じ世界に見えるよう、光は**上から柔らかく**（昼の回にしてもよい）
- 行き先は、話題を1つ見せるなら `/kinda-pair/topics`（一人の時間・住まいの形）。キャプションで1行だけ

**時期**：木曜は1枚リールと Kinda 紹介の隔週交互なので、**夜の窓（9/24）→ note 紹介（10/1 か 10/8）→ 間取り A** の順が自然。

Kinda が 9月にリーチ0を3本出した形そのもの。**IG の運用は真似しない。** 真似するのは言葉と、プロダクトの見せ方。

**言葉：何を「しない」かで定義している**

- IG bio：「紙の本のための、静かな読書ルーム。ひとりで読む。でも、ひとりきりではない。
  チャットもマイクもなし。ページをめくる音だけ。毎晩22:00、灯りをつけています。登録なしでどうぞ↓」
- 公式 X：「感想もメッセージもありません。ただ、そっと入って、そっと読んで、そっと出る。
  記録するのはページ数じゃなくて、本と過ごした時間だけ」

読み取れること：

1. **「しない」の列挙が、そのまま価値の説明になっている。** Kinda も同じ種類の「しない」を持っている
   （Kinda note は登録なし／pair は点数も相性も出さない・メッセージ機能を作らない）。**なのに bio で言っていない**
2. **時刻が"約束"ではなく"情景"で書かれている。**「毎晩22:00、灯りをつけています」。番組表ではなく、灯りがつく場所として書く
3. **bio の最後が「登録なしでどうぞ↓」。** 入口の敷居を最後の一言で下げて、そのままリンクに落とす。
   Kinda note も登録なしなので、**同じことが言える**（§14「note を bio に入れるか」への答え）

**プロダクトの見せ方：画面そのものが看板**

- X のヘッダーが**アプリの実画面**（等角のミニチュア図書室・狐たちが読んでいる・「◯人が、ここで読んでいます」）
- リリース告知の画像も**実画面のスクリーンショット**
- **プロダクトの画面が、それ自体かわいい**から成立している。Kinda の画面もクレイの絵が入っているので、同じことができる
  → 木曜の画面収録（10/8 案）はこの方向で正しい

**作り手の告知文の型（開発者個人の X・2026-08-19）**

共感の一文（「図書館っていいですよね」）→ 何を作ったか → **何をしないか** → **作り手のこだわり**
（「3Dキャラクターがリアルにページをめくることにこだわりました笑」）→ 試してほしい人（「積読ある方」）。
§1 の「唯一動いたのは作り手の話」と同じ。**X で Kinda note を紹介するときの型**に使える

**真似しないもの**

- 「◯人が、ここで読んでいます」のような人数表示。Kinda note は何も保存しないので**出せる数字がない**。作らない
- 顔出しの個人アカウント（CLAUDE.md §3：ふうかは顔を出さない）

**夜の窓（木曜1本目）との関係**：夜・灯り・気配の雰囲気が mekuru と重なる。
**違いは「ひとり」か「ふたり」か。** mekuru はひとりで読む部屋、夜の窓は関係を作っている最中の暮らし。
窓の中身を「ふたり分のもの」（マグ2つ・靴2足）中心にして、ここをはっきりさせる
