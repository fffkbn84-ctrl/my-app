## 6. 音（2026-09-27 ふうか「編集ありき・効果音アリ」）

**効果音は MP4 に焼き込む**（`tools/ig-carousel/add_sfx.py futari01`。numpy で合成するので権利の心配がない）。**音楽は Edits で足す。**

| 秒 | 画面 | 効果音 | 音楽 |
|---|---|---|---|
| 0.05 | 吹き出し | ポン | 明るい曲が始まる |
| 2.55 / 2.9 | 彼氏の吹き出し・伸び | ポン → 下がり笛「ひゅ〜ん」 | 続く |
| 5.30 | **彼女の真顔** | **カッ（拍子木）** | **ここで止める** |
| 5.55 | 吹き出し | ポン | 無音のまま |
| 7.60 / 7.95 / 8.35 | 彼氏が固まる | ピキーン → ポン → 汗「ぽた」 | 無音のまま |

**オチは「音楽が止まる」で作る。** 真顔の瞬間に BGM が切れて拍子木だけが鳴り、残り5秒は効果音だけ。無音の気まずさがそのまま彼氏の気まずさになる。

### Edits での手順（IG 公式の編集アプリ）

1. `kinda-ig-0927-futari01-sfx.mp4` を読み込む
2. 音楽を追加（候補は下）。**0秒から**置く
3. 音楽クリップを **5.3秒で分割 → 後ろ半分を削除**
4. 音量：元の音（効果音）100／音楽 40〜50
5. そのまま IG に投稿（IG の投稿画面では音楽を足さない）

Edits を使わない場合は、IG の投稿画面で音楽を足して音量を「元の音100／音楽30」にする（止める演出はなくなる）。
