## 2. IG「今日の天気、つけてみた」（木曜 note 紹介の枠・10/8(木) 20:00 案）

- **素材は本物の画面。** iPhone の画面収録はやめた（9/23）が、Claude 側でサイトを動かし、iPhone と同じ幅（390×844・3倍）で
  Playwright で撮れることを 10/4 に確認した。通知・ステータスバー・ブレは入らない。撮るときは Next の開発用マークを消す
- **答えはふうかさん本人が実際に選んだもの**にする（「使ってみた」なので、Claude が答えを作らない）。一言は映さない案
- カット（9:16・約14秒・版面は `render-reel.js` の型に合わせる）
  1. 1秒目：状況の言葉だけ「今日の気持ち、／うまく言えなかったので」（ズームなし・ブランド名から入らない）
  2. 質問の画面（選んだ答えに印）：「選ぶだけ、3つ」
  3. 結果のカード：「今日は、〇〇でした。」
  4. 「登録なしで、30秒。／プロフィールのリンクから」
- 曲は木曜のシリーズ用に決めたもの（のほほんは使わない）。カバーは1カット目を手動指定
- 状態：**MP4 書き出し済み（10/4）**。11.9秒・H.264・無音AAC入り。ファイルはチャットで納品（リポジトリには置かない）
  - 10/4 のふうかさんの答え：ほっとしていた × すこしだけ ×（Q3 は「晴れ系なら何でも」の一任で）このままで、いたい → **薄日**
  - カット：①質問の画面＋「今日の気持ち、／うまく言えなかったので」(58px) ②ほっとしていたを選んだ瞬間＋「選ぶだけ、3つ。」③薄日のカード＋「今日は、薄日でした。」④同＋「登録なしで、30秒。／プロフィールのリンクから」
