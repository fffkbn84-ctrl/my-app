## 2. 画像プロンプト（新規生成は2枚）

### A（カット1・2）— `【SCENE】`

```
One small round clay teacup without a handle (a Japanese yunomi), plain and
softly rounded, standing by itself with a faint wisp of steam, as if someone
has just poured tea and is about to sit down to talk.
```

### B（カット3）— `【SCENE】`

**A と同じスレッドで続けて生成し、下の1行を必ず足す。**

```
Two small round clay teacups of exactly the same shape, the same size and the
same color, placed side by side at the same angle with an equal gap between
them, neither one placed in front of the other — the two are given exactly the
same weight.
```

```
Keep exactly the same clay texture, the same object scale, the same camera angle, the same light direction and the same background as the previous image. Only the object itself changes.
```

**なぜ湯のみか。** 子どもを連想させる物（積み木・小さな靴・ゆりかご・芽の出た鉢など）は使わない。
絵が「子どもを持つ」側に寄り、望まない人・望んでも難しい人を外す。空の鉢も「実らない」に読めるので使わない。
この回で描くのは子どもではなく**「話すこと」**なので、話すときに手元にある物にした。

モチーフが大きすぎる／台座・床・壁・情景が写った／金属色が出た／2つの湯のみの大きさ・色が違う
