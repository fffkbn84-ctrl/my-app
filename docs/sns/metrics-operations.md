## 報告フォーマット

そのままチャットに貼ってください。空欄があっても構いません（取れなかった項目は空のままで結構です）。

### X

```
[日付] [投稿時間] インプ[ ] エンゲージメント[ ] プロフアクセス[ ] リンククリック[ ] 詳細クリック[ ]
```

### Instagram（共通）

```
[日付] 閲覧数[ ] リーチ[ ] プロフアクセス[ ] フォロー[ ] いいね[ ] 保存[ ] DMシェア[ ]
```

### Instagram（リールのときだけ追加）

```
3秒視聴継続[ ]% 平均再生[ ]秒 尺[ ]秒 スキップ率[ ]% 上位ソース：リールタブ[ ]% 発見[ ]%
```

同じ日に複数投稿がある日は、投稿タイトルか媒体を添えてください（火曜の X は朝と夜の2件あります）。

## 何を見て、何を捨てるか

追う指標を絞らないと、数字を見ること自体が目的になります。

| | 見る | 理由 |
|---|---|---|
| **主指標** | フォロワー増減（週次） | IG 戦略の目的はこれ一本（§7） |
| リール | **3秒視聴継続率** | 冒頭フックを変えた効果を測れる唯一の数字 |
| カルーセル | **保存数・DMシェア数** | 「人に送りたくなるか」がこの型の合否 |
| X | **エンゲージメント・プロフィールアクセス** | 読まれたかではなく、動いたか |
| **追わない** | リーチ・インプレッションの絶対値 | 既に出ていて、判断材料にならない（W27で確認済み） |

リーチは記録はします。判断に使わないだけです。

## いつ数字を取るか（二段構え）

投稿直後の数字と1週間後の数字は別物です。**確定の速さが指標ごとに違う**ので、2回に分けて取ります。

| 取るタイミング | 取る指標 | 理由 |
|---|---|---|
| **投稿の翌日〜2日後**（暫定） | X のインプ・エンゲージ／IG リールの**比率**（3秒視聴継続率・スキップ率・平均再生） | X は大半が最初の24〜48時間に出る。比率は初日でほぼ安定する |
| **投稿から1週間後**（確定） | IG のリーチ・閲覧／**保存数・DMシェア数**／フォロー | リールタブ配信は数週間伸び続ける。保存・シェアは絶対値なので積み上がりを待つ |

- **暫定値で方針を変えてよいのは比率だけ。** リーチ・保存・シェアの絶対値で判断を動かすなら確定値を待つ
- 暫定で入れた行は「振り返りメモ」に `暫定` と書き、確定値が来たら上書きする
- 1週間後に取り直すのは**その週の主役の投稿だけでよい**（全件やると続かない）

## レビューの頻度

- **月1**：`/sns-review` の月次レビュー。伸びた型だけ厚くする
- **週次レビューは行わない。** 週5〜7件・インプ2桁の規模では週次で差が読めず、レビューを書くこと自体が作業になる（2026-07 に週次タスクが2件未消化で積んだ実績）。フォロワーが2桁に乗ったら週次を再検討する
- Routine は毎朝「数字の入力」を催促する。これが週次レビューの代わりの継続装置
- 主指標（フォロワー増減）が3か月動かなければ、入口の形式そのものを変える（`ig-strategy-2026-09.md` §8）
