## 0. 結論（3行）

- **投稿の中身が悪いのではなく、投稿が「届く道」がない。** 3か月・約90本、どの柱も中央値10インプで同じ。本数を増やしても変わらない
- 小さいアカウントに効くのは **①人の投稿への返信（リプ回り）②画像 ③一言で答えられる問い** の3つ。今の X はこの3つとも0だった
- **1日3本は続けてよい**（連投の減点は、同じ人のタイムラインに同時に並んだときだけ）。ただし4本目を足すなら、**投稿ではなくリプ回り10件**にする

## 1. 数字（Notion「X投稿カレンダー」・9/12〜10/3 投稿の30本）

| | 値 |
|---|---|
| インプレッション | 合計333・**中央値10**・最大31・最小3 |
| 柱ごとの中央値 | B 10（9本）／A 9（5本）／C 10（5本）／D 8.5（4本）／E 14（3本）／**連載 30.5（2本）** |
| エンゲージメント | 30本で合計37（大半が詳細クリック＝本文を開いただけ） |
| プロフィールアクセス | **30本で1**（9/28 休会） |
| リンククリック | **30本で0**（セルフリプのインプは2〜19） |
| 7月（6/27〜7/6・約20本） | 中央値12・最大37 |

読み方：

- **7月から3か月、中央値が12→10で動いていない。** 柱・時間帯・文の型を変えても差が出ない＝中身の差ではなく、配られる量の上限に当たっている
- 唯一の差は**連載の2本（31・30）**。どちらもセルフリプが2本ついていて、投稿の下に会話の形があった。たまたまの可能性もある（2本だけ）
- **全30本がテキストのみ**。IG は同じクレイの絵でリーチ100〜1,580 に届いている
- 実際の投稿時刻が枠からずれている日が多い（朝枠が16:43、夜枠が0:19 など）。ただし今の量では時間帯の差は測れない

## 2. X の仕組み（2026 年に公開されたコードから）

xAI は 2026-01 に「おすすめ」の仕組みを GitHub（`xai-org/x-algorithm`）で公開し、4週ごとに更新している。
コードから読める事実と、そこから言えることを分けて書く。

### 2-1. 届く道は3つしかない

「おすすめ」に載る候補は、次のどれかから選ばれる。

| 道 | 中身 | Kinda の今 |
|---|---|---|
| フォロー中 | フォローしている人の新しい投稿 | **フォロワーがほぼいないので、ほぼ0** |
| 似ている人へ | 見る人と投稿を「意味のベクトル」にして、近いものを拾う（Phoenix retrieval）。どんな投稿に反応してきたかで見る人の位置が決まる | **Kinda の投稿に反応した人がほぼいないので、近くに置かれにくい** |
| 話題になっている投稿 | 全体で反応が集まっている新しい投稿 | 反応が集まっていないので載らない |

**中央値10の正体はここ。** 小さいアカウント向けの補正（下）は「候補に入った投稿を上に上げる」もので、候補に入る道は作ってくれない。

### 2-2. 並べ方：「この人が次に何をしそうか」の確率×重み

候補に入った投稿は、見る人ごとに「いいね・返信・リポスト・シェア・プロフィールを開く・フォロー・画像を開く・滞在時間…」
と「興味なし・ミュート・ブロック・通報」の確率を予測し、重みを掛けて足した点で並べる。

公開されている重み（解説記事が設定ファイルから読んだ値・2026-09 時点）：

| 行動 | 重み |
|---|---|
| リンクをコピーして人に教える | 20 |
| 返信（相互フォローの相手から） | 20 |
| 返信 | 5 |
| フォロー | 4 |
| いいね | 0.5 |
| 通報 | −234（確率に掛かるので「通報1件＝いいね468件」ではない） |

→ **いいねを集める投稿より、返信したくなる投稿・人に送りたくなる投稿が強い。**
今の C（問いかけ）は「何と言っていますか」のような**答えるのに文章が要る問い**で、返信は全回0だった。

### 2-3. 補正

| 補正 | 中身 | 意味 |
|---|---|---|
| **新しい・小さい投稿者の補正** | フォロワー1,000以下・表示1,000未満・48時間以内の**元投稿**（返信は対象外）を、上から16番目あたりまで引き上げる | 候補にさえ入れば、小さいことは不利ではない |
| 連投の減衰 | 同じ人の投稿が**1回の表示の中で**2本目以降に並ぶと0.5倍→下限0.25倍 | フォロワーがほぼいない今は、1日3本でも重なって見られることがほぼない。**3本は問題ない** |
| フォロー外 | フォローしていない人の投稿は0.75倍 | 全員フォロー外なので一律 |
| 48時間で候補から外れる | — | 古い投稿は掘り起こされない。毎日出す意味はある |

### 2-4. リンク

- 公開コードに「リンクなら減点」という行は**ない**（リンクのクリックはむしろ正の重み）
- ただ実測の報告では、**2026年3月以降、Premium でないアカウントのリンク付き投稿はほぼ届かない**という声が多い（第三者の計測・未検証）
- → **本文にリンクを入れない今のやり方は正しい**。ただしセルフリプのリンクも30本でクリック0なので、
  **リンクは B 柱と連載だけに絞る**（毎回つけない）

### 2-5. もう使えない道・お金で買える道

- **X コミュニティは 2026-05-30 に終了**。「コミュニティに投稿する」は使えない
- **X Premium**：返信が会話の上に出やすくなる・リンク付き投稿が届きやすくなる、とされる。
  **今は入らない**。リプ回りを2週間やって、返信が埋もれていると分かったら検討する（ふうか判断）

### 2-6. 返信（リプ回り）がいちばん効く理由

- 人の投稿への返信は、**その投稿を見に来た人の目に入る**。フォロワー0でも、届く道を借りられる
- 返信した相手・その投稿に反応した人と「近い」とみなされ、2-1 の「似ている人へ」の道が育つ
- ただし**フォロワー1,000以下の返信には専用のスパム判定がかかる**（コード上 `lte_1000`）。
  定型文・リンク付き・同じ文の連投はここに引っかかる

## 3. やること（10/8 から）

### 3-1. 自分の投稿：1日3本・型を変える

| 枠 | 型 | 変えること |
|---|---|---|
| 朝 7:30-8:30 | **B 相談所リアル**（検索される言葉を1行目に） | 7月の勝ち型のまま。セルフリプにコラム1本 |
| 昼 12:00台 | **画像か動画**（ぎっしり情景・ことさん・天気の絵） | **新設**。IG の素材をそのまま使う。番号・記号で答えられる問いを添える |
| 夜 21:00-22:30 | **C 問いかけ**（A/B/C で答えられる形）／A 天気（絵つき）／連載 | 問いを「文章で答える」から「**記号ひとつで答える**」に変える |

- 本文にリンクを入れない。セルフリプのリンクは **B・連載・告知だけ**
- **自分の投稿についた返信には、30分以内に全部返す**（返信の重み＋会話の形。名前は出さず、内容に一言＋問い返し）
- 画像の投稿には、**ふうかさんが最初の返信で自分の答えを書く**（「わたしは4番です」）。答え方の見本になる

### 3-2. リプ回り：1日10件（15分）

**探し方**：X の検索で「結婚相談所」「お見合い」「仮交際」「真剣交際」「婚活 疲れた」→「最新」タブ。
投稿から数時間以内・返信がまだ少ないものを選ぶ（伸びている投稿の上のほうに出る）。

**返していいもの**

- 相談所に入るか迷っている人の投稿 → 「初回面談で〇〇を聞くと分かりやすいです」のように、**具体的なひとつ**
- カウンセラーさんの投稿 → 自分の見方をひとつ足す（「仮交際の連絡で迷う人、多いですよね」で終わらせない）
- お見合い・デートの小さな報告 → その場面について一言（「別れ際に『楽しかったです』だけ置いて帰るの、いいと思います」）

**しないこと**

- リンクを貼る・Kinda の宣伝をする（スパム判定と信頼の両方で損）
- 同じ文を使い回す（スパム判定）
- 弱っている人の投稿に、頼まれていない助言をする。比べる・急かす言葉（CLAUDE.md §3）
- 相手探し目的の「婚活垢」への絡み・DM（出会いの場にしない）
- 空虚な共感だけの返信（「わかります」「すごい」で終わる）。**ひとつ具体的なことを返す**

### 3-2-b. リプ回りの気持ちの線（2026-10-10 ふうか合意）

> 「返信しないといけない」が負担で、投稿そのものが止まるほうが損。量より続くことを優先する。

- **本気で「それな」と思える投稿にだけ返す。** 10件は目安で、**2〜3件の日があってもいい**。気が向かない日はゼロでいい
- **斜めに見てしまう投稿（恋愛キャッキャ系・相談所への的外れな発言）には返さない。** 無理に合わせると嘘になり、皮肉で返すとブランドアカウントの事故になる
- 引っかかった投稿は**メモだけ取って、自分の投稿のネタにする**。引用・返信・特定はしない。
  あとで誰のことか分からない形にして「よく言われるけど、実はこう」を朝の B か夜の C で書く。
  斜めの視点は欠点ではなく、Kinda の「業界の常識をそっと外す」視点そのもの
- 面白いことを言わなくていい。返し方は3つで足りる：**一言足す**（「〜って言い換えると楽かも」）／**問いで返す**／**自分の経験をひとつ**
- 3-4 の優先順位はそのまま。リプ回りは3番目なので、しんどい日は飛ばしてよい

### 3-3. プロフィール

- **固定投稿を 9/15 の連載告知から、10/8 の「駅前の絵（番号つき）」に差し替える**。
  リプ回りでプロフィールに来た人が最初に見るのが、答えられる1枚になる

### 3-4. 1日3本が難しい日の優先順位

1. 自分の投稿についた返信に返す
2. 昼の画像1本
3. リプ回り10件
4. 朝の B
5. 夜の C

## 6. 10/21 の判定と、10/22 からのやり方（2026-10-21 ふうか合意「おすすめで進めたい」）

### 判定：§4 の「続ける条件」はどれも満たしていない

Notion「X投稿カレンダー」の 10/7〜10/18 投稿分（計測済み33本）より。

| 見る数字 | 条件 | 結果 |
|---|---|---|
| 画像のインプ中央値 | 20以上 | ぎっしり#1 が **47**。ほかの画像・動画は 14・9・6 |
| 返信がついた投稿 | 週3本以上 | **0本**（自分のリプだけ） |
| プロフィールアクセス | 週5以上 | **12日で2** |
| リプ回りの件数 | 記録する | **記録なし** |

- 朝 B は 10/7〜10/13 が中央値19（57 が1本）。**10/14 から 5・6・19・9 に下がった**。実際の投稿時刻が予定からずれた日と重なるが、理由は言えない
- 夜 C（文字・投票）は 10・8・9・6・7・6・8。形を3回変えても届く量が10以下のまま。**9人に見られて返信0は、問いの良し悪しを測れる数ではない**
- 試していない打ち手はリプ回りだけ

### 決めたこと

- **1日1本にする。** 浮いた時間は IG（`ig-strategy-2026-09.md` §21-c）に回す
- その日に IG の絵（ぎっしり等）があれば**昼に画像**。なければ**朝の B**
- **文字だけの C・A 天気・D つくる日記・F 中の人は止める**（11/18 に戻すか決める）。問いは画像の回の最初の返信に乗せる（「わたしは4番です」の形）
- リプ回りは**できる日だけ3件**（§3-2・3-2-b の線はそのまま）。やった日は件数を Notion の「振り返りメモ」に一言
- 計測は今までどおり投稿の3日後
- 次の判定は **11/18**（IG と同じ日）。見るのは「画像の中央値」「プロフィールアクセス」「リプ回りをした週としない週の差」。変わらなければ X は週2〜3本の置き場にする
