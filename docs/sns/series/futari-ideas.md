## 案1 付き合いたて「機嫌が悪い」→ ゲームオーバー（2026-09-27 ふうかメモ・**採用** → キット `packs/ig-reel-futari-gameover.md`）

### ふうかさんのメモ（原文の要旨）

- 付き合いたて。彼女の機嫌が悪い → なんでだろう、何したらいいんだろう、で**放っておく** → **ゲームオーバー**（ゲームっぽい画面と表記で）
- （ゲームっぽい画面のまま）**やり直すボタン** → 機嫌が悪い → 今度は「どうした？」「なんだった？」と**聞いてみる**
- キャプションで：男女問わず、相手がいつもと違ったら溜め込ませずに、気づいたときに聞いてみよう。
  いまは関係を築いている途中だから、こういう積み重ねが大事

### 試作で分かったこと（2026-09-27）

第1回のソファの絵に、RPG ふうのメッセージ窓と選択肢を載せて版面だけ試した（`tools/ig-carousel/render-game.js`）。

- **ドット文字（DotGothic16・npm の `@fontsource/dotgothic16`）＋黒い窓＋白い枠**で、一目でゲーム画面に見える
- **選択肢の「▶」が効く。** 「▶ そっとしておく」を選ぶ瞬間に、見ている側が「あっ」となる。
  しかも**そっとしておくは多くの人が正解だと思っている選択肢**なので、外れたときに笑いと気づきが同時に来る
- **ゲームオーバーの画面は生成しなくていい。** 同じ絵をモノクロにして暗く落とし、ドット文字を載せるだけで成立した
- やり直し後の画面は1カット目と同じ絵で、**カーソルの位置だけが「きいてみる」に移る**。これが一番おもしろい

### キャプション案

```
「そっとしておく」が正解の日も、たしかにあります。
でも付き合いたての「いつもと違う」は、聞いてほしいサインのことが多い。

溜めこむ前に、気づいたときに、ひとこと。
いまはふたりの関係をつくっている途中なので、
この小さな「どうした？」の積み重ねが、あとで効いてきます。

彼女でも彼氏でも、同じです。

#カップルあるある #付き合いたて #恋愛あるある #彼女の機嫌 #婚活
```

### トーンの線（セルフチェック）

- **「機嫌が悪い彼女」が女性の型に見えないか。** IG のネタ型では彼女・彼氏の役を使ってよい（2026-09-27 ふうか決裁）が、
  「女性はすぐ機嫌が悪くなる」と読まれると侮辱に寄る。対策は2つ：
  ① 笑う対象を**彼氏の「そっとしておく」判断**に置く（彼女は悪者にしない。ゲームオーバーの原因は放置のほう）
  ② キャプションに「彼女でも彼氏でも、同じです」を入れる。**反響がよければ、次は役を入れ替えた回（彼氏の機嫌が悪い）を作る**
- 焦らせない：ゲームオーバーは「きもちは　ためると　かたくなる」で、関係の終わりを言わない（「ふられた」「わかれた」は出さない）
- 空虚な共感ではなく、**「気づいたときに、ひとこと聞く」という具体的な一手**を返している
