## 0. この枠は何か

`ig-strategy-2026-09.md` §3 の **木曜 20:00 枠＝「深さ」層**。週3本の型のひとつ。

| | |
|---|---|
| **役割** | **プロフィールに来てもらう**（フォローでも保存でもない） |
| **形式** | カルーセル4〜6枚 |
| **1枚目に置くもの** | **作り手の判断**（世界観でも質問でもない） |
| **中身** | 作るときに迷ったこと、やめたこと、決めたこと |
| **CTA** | **置かない**（保存誘導もリンク誘導もしない） |

W27 実測で、リーチ100前後のリールはプロフ遷移0。唯一遷移を生んだのが
「なぜ Kinda を作ったのか」＝**中身と作り手の話**だった。だからこの枠は厚くする。

CTA を置かないのは `ig-strategy` §2「1投稿に2つ以上の役割を持たせない」に従うため。
この枠の役割は「作っている人に興味を持ってもらう」1つだけ。結論の枚で閉じる。

### 書くときの線

- **1枚目は一人称の判断で始める。**「〜と決めました」「〜を作りませんでした」「〜でつまずきました」
- **2枚目以降は断定を1つ減らす**（`ig-strategy` §5）。とくに**他人の心を断定している文**を緩める。
  例：「遅れていると思う人が出ます」→「**出てきます**」
- **評価語を置かない**（素敵・大事・すごい）。現象と判断だけを書く
- **失敗と、やめたことを出す。** うまくいった話より、やめた理由のほうがこの枠では効く
- 絵文字なし（CLAUDE.md §3）

### ハッシュタグ

**つくる日記だけ読者層が違う**ので、3〜5枠を作り手向けに振る（`ig-strategy` §6）。

```
#結婚相談所 #婚活 #真剣交際 #サービスづくり #ひとり開発
```

## 1. 画像

**新規生成は1枚だけ。** 1枚目にモチーフ、2枚目以降は文字のみ。

| 枚 | 画像 | 版面 |
|---|---|---|
| 1 | その回のモチーフ（毎回新規生成） | モチーフ中心 y=420・サイズ300／見出し 上端 y=690・**54px**・行間1.90・字間.07em |
| 2〜 | **なし**（背景 `#F5EEE6` のみ） | 文字ブロックを**天地中央**／**44px**・行間2.05・字間.08em |

- 全枚 **1080×1350（4:5）**、背景は厳密に `#F5EEE6`、Shippori Mincho 400・`#2E2620`
- 1行の上限：1枚目は**13字**、2枚目以降は**16字**
- **1枚目を火曜の連載と意図的に変えている。** 連載は 62px の疑問形、つくる日記は 54px の断言形。
  グリッドに並んだとき、火曜と木曜が見分けられる

### モチーフのプロンプト

共通テンプレートと作法は `docs/sns/series/iinikui-kimochi.md` §1・§2 と**同じもの**を使う。
`【SCENE】` だけ毎回差し替える。

**つくる日記の `【SCENE】` を考えるときの追加ルール**：

- **その回の結論を、配置で言わせる。** 説明の絵ではなく、主張そのものの形にする
- **順位・進捗・優劣に読める配置を避ける。** 一列・縦積み・階段状は、それだけで「順番」を語ってしまう
- 図解にしない（矢印・目盛り・記号を入れない）

実績（第1回「層を進捗にしなかった話」）：

```
Four tiny clay vessels of the same width but different depths — a very shallow
plate, a slightly deeper dish, a small bowl, and a deep cup — arranged in a
ring, evenly spaced, so that none of them comes first and none comes last.
All four are empty.
```

> 生成されたのは輪ではなく**2×2のかたまり**だったが、そのまま採用した。
> この回の主張は「順番を進捗にしない」で、**一列でも縦積みでもなければ目的は果たせる**。
> 器の深さの違いが「層は深さです」を、順番の読めない配置が「どの層から始めても」を同時に担う。
> 1枚の絵で結論が2つ出ている状態が理想。

**この回の採否基準**（回ごとに立てる）：一列に並んだら再生成／浅い順に整列したら再生成／
器の中に何か入っていたら再生成（満たす・満たさないに読める）／目盛りや数字が出たら再生成。

## 2. 第1回「層を進捗にしなかった話」（2026-09-17・実績）

Notion IG投稿カレンダー：`つくる日記｜層を進捗にしなかった話`。カルーセル4枚。

| 枚 | 本文 | 改行 |
|---|---|---|
| 1 | 話題の順番を、進捗にしないと決めました。 | 話題の順番を、／進捗にしないと決めました。 |
| 2 | 浅い順に並べると、上から消していくリストに見えてしまいます。 | 浅い順に並べると、／上から消していくリストに／見えてしまいます。 |
| 3 | そうなると、遅れていると思う人が出てきます。 | そうなると、／遅れていると思う人が／出てきます。 |
| 4 | 層は深さです。どの層から始めても構いません。 | 層は深さです。／どの層から始めても構いません。 |

キャプション：

```
28個の話題を並べるとき、いちばん迷ったのは順番でした。
浅い順に並べると「まだそこまで話せていない」と読めてしまうので、層は進み具合ではなく深さとして置いています。

#結婚相談所 #婚活 #真剣交際 #サービスづくり #ひとり開発
```

### 下書きから2か所直した

1. **3枚目「出ます」→「出てきます」。** 他人の心を断定している文なので、ここを緩めるのが一番効く
   （`ig-strategy` §5・Notion のメモ自身の指示）
2. **4枚目「どの層から触れても」→「どの層から始めても」。** 漢字なので誤読は少ないが、
   **層名の「ふれる」と紛れる**（同じ語が別の役で二度出る）。意味を変えずに紛れだけ消した。
   層名の扱いは `kinda-pair-28.md`「4枚目の書き方（層）」も参照

## 3. 手順（Claude の担当）

1. このファイルと `docs/sns/ig-strategy-2026-09.md` を読む
2. Notion「IG投稿カレンダー」から該当回の**枚ごとの本文**を取る
   （データソース `collection://547cadc2-95cb-4839-a559-7bd64c371d83`・`メモ` 欄）
3. 本文を §0 の線でセルフチェックし、直す場所があれば**理由つきで提案する**
4. **共通テンプレートを提示し、その回の `【SCENE】` を §1 の作法で新しく考えて出す**
5. ふうかさんが ChatGPT で生成 → チャットに貼る
6. スクリプトで処理・文字入れ → 全枚返す

```bash
python3 prep.py <生成画像.png> tsukuru-bg-01.png 300 420
NODE_PATH=$(npm root -g) node render-series.js note tsukuru-bg-01.png out-01.png '["行1","行2"]'
NODE_PATH=$(npm root -g) node render-series.js body none               out-02.png '["行1","行2","行3"]'
```

7. Notion の該当ページに決定事項を追記（`状態` は投稿後に `投稿済` へ）

### やらないこと

- CTA 枚を足さない（保存誘導もリンク誘導もしない）
- 2枚目以降に絵を置かない
- 1枚目を 62px にしない（火曜の連載と見分けがつかなくなる）
