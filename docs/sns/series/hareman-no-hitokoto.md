# 晴れ間のひとこと（X のカード型・2026-10-22 ふうか決裁）

> 型の正はこのファイル。書き出しは `docs/sns/tools/ig-carousel/render-hareman.js`。
> X の運用全体は `docs/sns/x-strategy-2026-10.md` §6、IG は `ig-strategy-2026-09.md` §21。

## 0. なぜこの型か

- 10/22 の会議で、ふうかさんが X の「読ませるカード」（コンサル辞典）と「漫画」を持ってきた。結論は**カードを X で始める**。漫画はいまのゲームオーバー型とほぼ同じなので足さない
- X で数字が出たのは画像だけ（ぎっしり#1 が47。文字だけは10前後）。X は読む場所で、カードは「あとで使う」から保存される
- 辞典の形は元のアカウントに近すぎる（ふうか）。形ごと替えて、**天気予報の形**にした。雲の2体の「気持ちが体の天気に出る」設定と Kinda の天気の軸にそのまま乗る
- IG の4週間ルール（主役はゲームオーバー・11/18 判定）の外なので、いつ始めてもいい。IG に出すかは 11/18 に決める（出すなら「場面 → 晴れ間」の2〜3カットのリール）

## 1. 中身の線（ここがいちばん大事）

**本音で、本当に役立つ対人の技術。** モテテクではない。参考の方向は『RAPPORT 最強の心理術』のような、相手と話しやすくなるための技術（ふうか）。

- **「相手を動かす」を前に出さない。** 相手が話しやすくなる・自分で決められる側で書く。操作に読めた時点で信頼が落ちる
- **根拠のある話だけ使う。** X は突っ込まれる場所。研究を使うときは出どころをこのファイルの各回に書く。うろ覚えの心理学（〇〇効果で落とせる等）は使わない
- **言った人も言われた人も悪者にしない。** 元ネタのような皮肉はしない（CLAUDE.md §3 侮辱的に読まれうる表現を避ける）
- **焦らせない・比べない。** 「これを言えないと次はない」の形にしない
- **性別を決めない。** 「相手」で書く
- お見合い・交際・結婚相談所の語は使ってよい（X の投稿本文。ヒーロー・CTA ではない）
- **場面は相談所の決まりに合わせる。** お見合いのあとは直接連絡できない相談所が多い。お見合い後の連絡を前提にした場面は作らない（交際に入ってからにする）

### あるあるか実用か

毎回悩まなくていいように3段を固定する。**あるあるは入口、実用が中身。**

1. **場面**（あるある。読んだ人が「ある」と思う1場面）
2. **空模様**（なぜそうなるか。本音で、相手の側の事情を言う。天気は1語：くもり・小雨・霧・強い風など）
3. **晴れ間のひとこと**（そのまま口に出せる一言。カギカッコで書く）

### 晴れ間のひとことは毎回いっしょに考える（ふうか指示）

- Claude は**候補を3つ**出し、それぞれ「なぜ効くか」を1行つける。ふうかさんが選ぶか直す
- 合格の条件：
  - そのまま言える長さ（目安30字以内）
  - 相手が答えやすい（はい・いいえで終わらない／答えを決めつけない）
  - 相手が断れる・選べる余地がある
  - 言う人が無理をしていない（キャラを作らないと言えない言葉は落とす）

## 2. 版面（render-hareman.js）

4:5（1080×1350）。X のタイムラインで切れない比率。

- 上：「晴れ間のひとこと」と番号
- 場面：太字50px・3行まで
- 空模様：ラベル＋天気1語（青灰）＋本文32px・3行まで
- 晴れ間のひとこと：ローズのラベル＋太字46px・3行まで
- 右下：雲の2体（下の画像を使い回す）
- 文字は全部スクリプトで入れる。はみ出したら止まる

```bash
cd docs/sns/tools/ig-carousel   # フォントの準備は README のとおり（700 も使う）
cp package/files/shippori-mincho-japanese-700-normal.woff2 ./shippori700.woff2
NODE_PATH=$(npm root -g) node render-hareman.js <雲の画像> out.png \
 '{"no":"01","scene":["行1","行2","行3"],"sky":"くもり","why":["行1","行2","行3"],"line":["行1","行2","行3"]}'
```

改行は自分で入れる（自動で折り返さない）。1行は場面14字・空模様17字・晴れ間12字くらいまで。

## 3. コラムにも載せる（ふうか指示）

**カードを出すときは、同じ話題でコラム（`/columns`・サイト上の名前は Kinda voices）も出す。**

- カテゴリは **「お見合いと交際のこと」**（「取材レポート」は取材記事専用なので使わない）
- 書き方は `/kinda-column` スキル（キーワード設計・QA・PR まで）。文は CLAUDE.md §3「文の書き方」
- 中身：場面 → なぜそうなるか（出典つき） → 晴れ間のひとこと → ほかの言い方2〜3個 → 言わないほうがいい言い方とその理由 → 関係する Kinda pair の話題（`/kinda-pair/topics`）へ内部リンク
- カードの画像を記事の中に置く
- X ではリンクを本文に入れない（届きにくくなる・x-strategy §2-4）。**カードの最初の返信にコラムのリンク**を置く。だからコラムは X より先か同じ日に公開する

## 5. 下書き（No.01〜03・10/22）

晴れ間のひとことは確定ではない。出す前にふうかさんと決める。

### No.01 休日の話が止まる

- 場面：お見合いで「休日は何を？」／と聞いたら「家でゆっくりです」／で終わってしまった
- 空模様：くもり／答えが短いのは話したくないから／とは限りません。何をどこまで話せば／いいか、まだ探っているだけです。
- 晴れ間の候補：
  1. 「ゆっくりの日って、何してるときがいちばん好きですか？」（見本で使用）— 答えを受け取ってから聞き返すので、ちゃんと聞いていると伝わる
  2. 「家だと、どこにいる時間が長いですか？」— 場所は答えやすく、そこから話が広がる
  3. 「わたしも家派です。最近ゆっくりできた日ありました？」— 先に自分を少し出すと、相手も出しやすい
- 根拠：相手の答えに重ねて質問する人ほど好かれる。スピードデートでは質問が多い人ほど「また会いたい」と言われた（Huang et al., 2017, *Journal of Personality and Social Psychology*「It doesn't hurt to ask」）

### No.02 デートのあとに落ちこむ

- 場面：初めてのデートのあと／「うまく話せなかった」と／ひとりで反省会をしている
- 空模様：小雨／人は会話のあと、相手が自分を／どれくらい好ましく思ったかを／低く見積もりがちです。
- 晴れ間の候補：
  1. 「〇〇の話、もっと聞きたかったです」— 反省より、相手の話で覚えていることを1つ渡す
  2. 「今日、〇〇が楽しかったです」— 自分の評価ではなく、楽しかった1点だけを言う
  3. 「また〇〇の続き聞かせてください」— 次に話す理由を相手に残す
- 根拠：会話の相手は、こちらが思うより自分を好ましく思っている（liking gap。Boothby et al., 2018, *Psychological Science*）
- 場面は交際に入ってから（お見合い後の直接連絡は前提にしない）

### No.03 重い話題で黙られた

- 場面：子どものことを聞いたら／相手が黙ってしまった
- 空模様：霧／黙るのは答えがないからではなく／まだ言葉になっていないことが多いです。／急かされると人は身構えます。
- 晴れ間の候補：
  1. 「いま答えなくて大丈夫です。まとまったら聞かせてください」— 答えるかどうかを相手が選べる
  2. 「わたしもまだ決めきれてないんです」— 先に自分の迷いを出すと、相手も迷っていていいと分かる
  3. 「この話、またいつかしませんか」— 話題を閉じずに置いておける
- 根拠：相手が選べる余地を残すと、人は身構えずに話しやすくなる（動機づけ面接の「自律性の尊重」。『RAPPORT』も同じ考え）
- Kinda pair の「いまは置いておく」とつながる。コラムから `/kinda-pair/topics` の子どもの話題へ内部リンク
- 同じ週に IG で子どもの話題を出さない（近似重複）
