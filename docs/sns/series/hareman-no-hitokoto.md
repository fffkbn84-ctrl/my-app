# 晴れ間のひとこと（X のカード型・2026-10-22 ふうか決裁）

> 型の正はこのファイル。書き出しは `docs/sns/tools/ig-carousel/render-hareman.js`。
> X の運用全体は `docs/sns/x-strategy-2026-10.md` §6、IG は `ig-strategy-2026-09.md` §21。

## 0. なぜこの型か

- 10/22 の会議で、ふうかさんが X の「読ませるカード」（コンサル辞典）と「漫画」を持ってきた。結論は**カードを X で始める**。漫画はいまのゲームオーバー型とほぼ同じなので足さない
- X で数字が出たのは画像だけ（ぎっしり#1 が47。文字だけは10前後）。X は読む場所で、カードは「あとで使う」から保存される
- 辞典の形は元のアカウントに近すぎる（ふうか）。形ごと替えて、**天気予報の形**にした。雲の2体の「気持ちが体の天気に出る」設定と Kinda の天気の軸にそのまま乗る
- IG の4週間ルール（主役はゲームオーバー・11/18 判定）の外なので、いつ始めてもいい。IG に出すかは 11/18 に決める（出すなら「場面 → 晴れ間」の2〜3カットのリール）

## 1. 中身の線（ここがいちばん大事）

**本音で、本当に役立つ対人の技術。** モテテクではない。参考の方向は『RAPPORT 最強の心理術』のような、相手と話しやすくなるための技術（ふうか）。

- **「相手を動かす」を前に出さない。** 相手が話しやすくなる・自分で決められる側で書く。操作に読めた時点で信頼が落ちる
- **根拠のある話だけ使う。** X は突っ込まれる場所。研究を使うときは出どころをこのファイルの各回に書く。うろ覚えの心理学（〇〇効果で落とせる等）は使わない
- **言った人も言われた人も悪者にしない。** 元ネタのような皮肉はしない（CLAUDE.md §3 侮辱的に読まれうる表現を避ける）
- **焦らせない・比べない。** 「これを言えないと次はない」の形にしない
- **性別を決めない。** 「相手」で書く
- お見合い・交際・結婚相談所の語は使ってよい（X の投稿本文。ヒーロー・CTA ではない）
- **場面は相談所の決まりに合わせる。** お見合いのあとは直接連絡できない相談所が多い。お見合い後の連絡を前提にした場面は作らない（交際に入ってからにする）

### 題材は「ふたりの間で実際に言われる言葉」（10/22 4回目の改定・ふうか）

コンサル辞典が刺さる理由を分解した結果：

1. **見出しが、だれもが聞いたことのある実在の言葉**
2. **説明で、建前の裏にある本当の働きを言い当てる**
3. **最後にひとことで落とす**
4. キャプションは「〜で出る言葉、第1位」。順位の形で開かせる

Kinda 版はこの 1〜4 を使う。変えるのは2つ：

- **皮肉で落とさない。** なぜそう言うのかを、言った人の側からやさしく読み解く
- **落ちの代わりに「晴れ間のひとこと」で次の一手を渡す**

題材の取り方：

- **一対一の、ふたりの間で実際に言われる言葉**（デート・LINE・予定を決めるとき・帰り道）。仲人どうしの断り文句のような**仕組みの言葉は使わない**（自分ごとにならない・ふうか）
- 婚活の場で生まれる言葉（お見合いの席での一言など）も、**ふたりの間の言葉なら**使ってよい
- 「わたし／ぼく」「彼／彼女」で性別を決めない。主語はなくすか「自分」
- 作った言葉は使わない。読んだ人が「言った」「言われた」と思える言葉だけ

### 出典は画像に入れない（ふうか）

カードには出典を書かない。添えるときは**キャプション**に書く。研究を使う回は、キャプションの最後に1行。

### 3段（版面の順）

1. **どこで聞く言葉か**（小さく1行：「ふたりで予定を決めているときに」）
2. **その言葉**（いちばん大きく・できれば1行・カギカッコ）
3. **空模様**（天気1語＋**なぜその言葉を言うのか・どんなときにそうなりがちか**。3行まで。言った人の側から）
4. **晴れ間のひとこと**（太字2〜3行。**その言葉を言ってしまう自分が、代わりにこう言えば伝わる**という言い換え）

### 最後は「自分ごと」で終わる（10/22 ふうか・Claude 合意）

- 晴れ間は**言う側の言い換え**。言われた側の返し方は書かない（そういう相手にいつも相手側が対処する形に見せない・ふうか）
- 読んだ人が「これ自分だ」で保存する。相手に送っても責める形にならない
- **言い方を直させない。** 元の言葉は悪くない。「言えなかった続きを足す」形にする（例：「どれも楽しそうだな〜。強いて言えば〇〇かな」）
- くもった言い方（空模様）が晴れた言い方（晴れ間）に変わる、が型の名前と重なる
- **言い換えは話し言葉で書く。** 「どっちでもいい」のような文字にすると冷たく見える語を避け、「〜だな〜」「〜かな」の温度を残す（10/22 ふうか修正から）

### 晴れ間のひとことは毎回いっしょに考える（ふうか指示）

- Claude は**候補を3つ**出し、それぞれ「なぜ効くか」を1行つける。ふうかさんが選ぶか直す
- 合格の条件：
  - 題として**2行・1行7字くらい**に収まる
  - 読んだ次の日にそのまま使える
  - 相手に何かを強いない（相手が断れる・選べる）
  - 言う人・やる人が無理をしていない

### 目的（10/22 ふうか）

**ファンを作る・送信されて知ってもらう。** 型の中身はこの2つで判断する。正しさや安全さだけで選ばない。

### 案（未決）：同じカードで「注意報」の回を混ぜる

ふうか「たまにはダメなことはダメと強めに言い切るものも出したい」。

- 枠と見た目は同じ。左上の「晴れ間のひとこと」を **「注意報」** に替え、天気は雷・強風
- 中身は言い切り。例：「試すための既読無視は、しなくていい」「『普通は』で相手の気持ちを決めない」
- 晴れ間は保存されやすく、注意報は「これ見て」と送られやすい。2つで目的の両方を取りにいく
- 言い切ってよいのは**行動**。人や性格は言い切らない（CLAUDE.md §3 侮辱的に読まれない）
- CLAUDE.md §3 の「断定より寄り添い」から外れる回になる。出すなら比率は晴れ間3：注意報1くらい

### 案（未決）：日常の切り取りは雲の2体で

まめきちまめこのような日常の切り取りは、ファンを作る力がいちばん強い。ただカードに混ぜると型がぶれる。やるなら**雲の2体の日常**として別の枠にする（IG のゲームオーバーと同じキャラ）。IG の判定（11/18）のあとに決める。

### このセッションのすれ違いの記録（10/22・次から気をつける）

1〜5回目で題材と終わり方が毎回ずれた。原因は Claude 側にある。

- **ルール（焦らせない・寄り添い・根拠）で先に削ってから出していた。** 安全だが、送りたくなる強さが消える。先に「送りたくなるか」で選び、ルールは最後の確認に使う
- **ふうかさんの「調査力」を出典集めと受け取った。** 求められていたのは題材を見つける目（何が人の心に引っかかるか）
- **合意する前に毎回ファイルと画像まで作っていた。** 先に方向を1行で確かめてから作る
- **言い換えを書き言葉で作っていた。** 「どっちでもいい」は理屈では正しくても、文字にすると冷たい。話し言葉の温度で書く

## 2. 版面（render-hareman.js）

4:5（1080×1350）。X のタイムラインで切れない比率。10/22 に作り直した（最初の版は題が目立たず文字が多かった・ふうか）。

- 左上：小さな太陽の丸＋「晴れ間のひとこと」。右上に番号
- 場所：40px・1行
- **晴れ間のひとこと：極太（Shippori 800）104px・2行**。`[ ]` で囲んだ語にローズの帯
- 空模様：天気1語のラベル＋理由32px・**2行まで**
- 右下：雲の2体（下の画像を使い回す）。カードの枠は付けない
- 文字は全部スクリプトで入れる。はみ出したら止まる

```bash
cd docs/sns/tools/ig-carousel   # フォントの準備は README のとおり（700 も使う）
cp package/files/shippori-mincho-japanese-800-normal.woff2 ./shippori800.woff2
NODE_PATH=$(npm root -g) node render-hareman.js <雲の画像> out.png \
 '{"no":"01","place":"初対面のカフェで","title":["コーヒーには","[お水]をそえる。"],"sky":"くもり","why":["行1","行2"]}'
```

改行は自分で入れる（自動で折り返さない）。題は1行7字・理由は1行19字くらいまで。

### 雲の2体の画像（一度作れば使い回す）

見本（10/22）は `assets/futari/tenki-go3-6-sunny-v1.webp`（ゲームオーバー3の6枚目）を借りた。手に持ち物があるので、カード専用に**持ち物なしの2枚**を作る。設定画 `assets/futari/tenki-reference-v1.webp` を添付して、ゲームオーバー型の共通テンプレート（`packs/2026-10-20-ig-reel-futari-gameover-03.md` §2）の【ACTING】を差し替える。

## 3. コラムにも載せる（ふうか指示）

**カードを出すときは、同じ話題でコラム（`/columns`・サイト上の名前は Kinda voices）も出す。**

- カテゴリは **「お見合いと交際のこと」**（「取材レポート」は取材記事専用なので使わない）
- 書き方は `/kinda-column` スキル（キーワード設計・QA・PR まで）。文は CLAUDE.md §3「文の書き方」
- 中身：場面 → なぜそうなるか（出典つき） → 晴れ間のひとこと → ほかの言い方2〜3個 → 言わないほうがいい言い方とその理由 → 関係する Kinda pair の話題（`/kinda-pair/topics`）へ内部リンク
- カードの画像を記事の中に置く
- X ではリンクを本文に入れない（届きにくくなる・x-strategy §2-4）。**カードの最初の返信にコラムのリンク**を置く。だからコラムは X より先か同じ日に公開する

## 4. 出す頻度

- まず**週2本**。X は1日1本なので、その日の「朝 B」と入れ替える
- コラムを毎回書くので、毎日にはしない。数字が出たら増やす
- 判定は X と同じ 11/18（画像のインプ中央値・保存・プロフィールアクセス）

## 5. 題材の候補（10/22 5回目・晴れ間は言う側の言い換え）

晴れ間は仮。出す前にふうかさんと決める。見本を描いたのは①。

| # | どこで | その言葉 | 空模様（なぜ・どんなとき） | 晴れ間のひとこと（仮） |
|---|---|---|---|---|
| ① | 予定を決めているときに | 「別にいいけど」 | 小雨：本当は行きたい場所がある。でも言ったらわがままに見えそうで、「けど」に気持ちを残してしまう | 「どれも楽しそうだな〜。強いて言えば〇〇かな」（ふうか修正：「どっちでもいい」は文字にすると突き放して見える） |
| ② | 少し空気が重いときに | 「怒ってないよ」 | くもり：怒ってはいない。でも残念だったことがあって、言うと責めているようで飲み込む | 「怒ってはないよ。ちょっと残念だっただけ」 |
| ③ | 相談するときに | 「どう思う？」 | 晴れ：もう答えはある。背中を押してほしいのに、先に言うと否定されそうで聞いてしまう | 「こうしようと思ってるんだけど、どう思う？」 |
| ④ | デートの途中で | 「疲れてない？」 | うす曇り：疲れているのは自分。でも「疲れた」と言うと楽しくないみたいで、相手に聞く形にする | 「ちょっと疲れてきた。お茶して帰らない？」 |
| ⑤ | 帰り道に | 「自分の話ばっかりでごめんね」 | 晴れ間：楽しかった。でもしゃべりすぎた気がして、謝る形で終わらせてしまう | 「聞いてくれてうれしかった。次はそっちの話も聞かせて」 |
| ⑥ | 相手の話を聞いて | 「えー、すごい！」 | 霧：ちゃんと聞いている。でも何と返せばいいか分からないときに出る | 「すごい。それ、どうやったの？」 |
| ⑦ | 別れ際に | 「また行きましょう」 | うす曇り：本当にまた会いたい。でも重く見えないように、ふわっと言ってしまう | 「次は〇〇行ってみたいです」 |

- ⑥ は「中身のない共感をしない」（CLAUDE.md §3）と重なる
- ③ ⑥ はキャプションに研究を1行添えられる（聞き返しの質問が多い人ほど好かれる：Huang et al., 2017）
- 同じ週に IG のゲームオーバーで近い話題を出さない（①は 10/20「行き先が決まらない日」に近い。初回をその週から離す）

### 保留

- **婚活の仕組みの言葉**（10/22 3回目）：「会話のテンポが合わなかった」「壁を感じる」など。仲人どうしの言葉で自分ごとになりにくい（ふうか）。コラムの題材には使える
- **狭い場面×小さな手順**（10/22 2回目）：コーヒーにはお水をそえる／「着きました」に目印 ほか。合間の軽い回に使える
- **広い題材**（10/22 1回目）：休日の話が止まる／反省会／重い話題で黙られた
