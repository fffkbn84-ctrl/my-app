## 0. この枠は何か

`ig-strategy-2026-09.md` §3 の **土曜 12:00 枠＝「入口」層**。週3本の型のひとつ。

| | |
|---|---|
| **役割** | **非フォロワーに届く**（リールタブ経由。フォローでもプロフ遷移でもない） |
| **形式** | リール 15〜20秒・9:16 |
| **1秒目に置くもの** | 相手の**状況の言葉**。`topics.ts` の `ask` をそのまま使う |
| **中身** | **翌火曜の連載の話題を開く**。連載と同じ `topic_key` |
| **CTA** | 保存誘導のみ（「保存して、会う前に見返してください」） |
| **合否指標** | **3秒視聴継続率**（W27 は12〜20%。8割が3秒以内に離脱している） |

**1秒目に置いてはいけないもの**：風景だけのカット、詩的な一行、ブランド名、ロゴ、
「〜な夜に。」で始まる情緒的な導入（スキップ率92%だった雨リールがこれ）。

判定基準はひとつ。**その1文を読んだ人が「これは自分のことだ」と思うか。**

## 1. 見た目は単色スタイル（2026-09-19 変更）

**背景 `#F5EEE6` の単色＋小さなクレイのもの1つ。カルーセルと同じ。**

> **旧方針（木の台座つきミニチュアジオラマ）は使わない。**
> あの指定は 2026-09-12 に書かれたもので、**9/14〜9/17 の3投稿で確立した単色スタイルより古い**。
> リールもプロフィールのグリッドに並ぶため、ここだけジオラマにすると2つのアカウントが混ざって見える。
>
> もうひとつ。リールの仕事は**1秒目に文字を読ませること**で、情報量の多いジオラマは文字と competing になる。
> 単色のほうが文が立つ。3秒視聴継続率を上げるのが目的なら、絵は引くのが正しい。

## 2. カット構成（絵3枚 × 文5つ）

**絵は3枚で足りる。** 毎カット新しい絵を作ると週5枚になり、ひとり運用が続かない。
**物の配置の変化で、文の流れをなぞる**のがこの型の設計。

第1回（`l2-contact` 連絡の頻度とテンポ）の実績：

| # | 秒 | 文字 | 絵 |
|---|---|---|---|
| 1 | 0〜3.5 | 連絡って、／こまめな方が安心ですか？ | **A**：伏せたスマホ1台 |
| 2 | 3.5〜7.5 | 交際中、いちばん行き違いが／起きるところです。 | A（ゆっくり寄る） |
| 3 | 7.5〜12 | 相手のやり方を直す話にすると、／角が立ちます。 | **B**：少し離れた2台 |
| 4 | 12〜16.5 | お互いの既定を確かめる話として／置けば、そのまま聞けます。 | **C**：並んだ2台 |
| 5 | 16.5〜17.9 | 保存して、会う前に／見返してください。 | C（続き） |

「1台 → 離れた2台 → 並んだ2台」で、問題 → すれ違い → 置き方を変える、をなぞっている。

### 版面（1080×1920）

| 項目 | 値 |
|---|---|
| モチーフ | 中心 y=**680**・サイズ**340** |
| 文字ブロック | 上端 y=**1120**（IG の下部UIに被らない位置。**y=1500 より下に置かない**） |
| 1秒目 | **58px**・行間1.90・字間.07em（1行**12字**まで） |
| 2カット目以降 | **48px**・行間2.00・字間.08em（1行**16字**まで） |
| 書体・色 | Shippori Mincho 400 / `#2E2620` / 背景 `#F5EEE6` |

### 動き

- **1カット目はズームなし。** 1秒目は文字を読ませる時間で、動きが邪魔になる
- 2カット目以降は **1.04倍までのゆっくりズームイン**。最後だけ 1.04→1.07 で押し切る
- カット間は**クロスディゾルブ 0.4秒**。フラッシュやスライドは使わない

## 3. モチーフのプロンプト

共通テンプレートと作法は `docs/sns/series/iinikui-kimochi.md` §1・§2 と**同じもの**。
**1:1（正方形）で生成する**（理由は §5）。

**入口リールの `【SCENE】` を考えるときの追加ルール**：

- **3枚が「同じ物の、配置違い」になるように組む。** 別々の物にすると絵が散る
- 変化は**数と距離**で作る（1つ→離れた2つ→並んだ2つ、など）
- 煽りの記号を入れない（通知バッジ・未読数・光る画面は「早く返せ」に読める）

実績（第1回 `l2-contact`）：

```
A — One tiny clay smartphone lying face down, screen against the surface, all alone.
Its back is plain and smooth with no camera lenses, no buttons and no markings.

B — Two tiny clay smartphones, both lying face down, placed apart from each other
with a clear gap between them and turned at slightly different angles, as if
each was set down at a different moment.

C — Two tiny clay smartphones, both lying face down, placed neatly side by side
at the same angle with only a small even gap between them.
```

採否基準（この回）：画面が光っていたら再生成／通知マーク・アイコン・数字が出たら再生成／
Bで片方が明らかに手前・大きいと優劣が出るので再生成。

## 4. 書き出しと投稿

```bash
python3 prep.py <生成画像.png> reel-A.png 340 680 1080 1920
NODE_PATH=$(npm root -g) node render-reel.js hook reel-A.png f1.png '["行1","行2"]'
NODE_PATH=$(npm root -g) node render-reel.js body reel-B.png f3.png '["行1","行2"]'
python3 build_reel.py        # SEGS を書き換えて実行。H.264 / 無音 / 1080x1920
```

- 出力は **H.264・yuv420p・30fps・無音AACトラック入り**。IG にそのまま上げられる
- **音楽は IG 側で足す。無音のまま投稿しない**（リールは音ありが既定再生）。
  歌詞のある曲は文字と competing になるので、ピアノかアコースティックの静かなもの。音量は控えめに
- **カバーは1カット目（`f1.png`）を手動で指定する。** IG に選ばせると中間のフレームが選ばれ、
  グリッドに質問が出なくなる
- ふうかさんの声を入れてもよい（CLAUDE.md §3 で音声は可・顔出しはしない）

---

## 5. 1:1 で生成する理由

`prep.py` は**モチーフだけ切り出して任意の比率のカンバスに置き直す**ので、
1:1 で1回生成すれば **リールの 1080×1920 と火曜カルーセルの 1080×1350 の両方に使える**。

第1回では、土曜リールの **B（少し離れた2台）が、翌火曜 9/22 の連載第2週の1枚目にそのまま使える**。
**土曜と火曜で同じ話題を扱う設計なので、この使い回しは毎週成立する。**
週あたりの生成は実質3枚（リール3枚のうち1枚が火曜へ回る）。
