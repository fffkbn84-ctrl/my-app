# 「ぎっしり情景」型 — 1枚の中から自分を探すリール

- **決裁**：2026-10-04 ふうか（CLAUDE.md §7-b の「単色＋物1つ・人を入れない」の例外）
- **枠**：決まった曜日を持たない。空いている枠に入れる（第1回は 10/5 月 20:00）
- **書き出し**：`render-labels.js` ＋ `build_reel.py one10`（`docs/sns/tools/ig-carousel/`）

## なぜやるか

参考は @koarasan_genkai（フォロワー5.3万・1,000万再生5本）の「〇〇の日常 5場面」「〇〇別 ×× N選」。
1枚にたくさんの人がいて、ひとりずつに短いラベルが付いている。見た人はその中から**自分や知り合いを探して止まり**、
「これあなた」と**送る**。

うちの数字も同じ方向を指している。3秒残存が高かったのは、並べる型#1（36%）・夜の窓（31%）・間取り（26%）＝
**並んだ中から自分を探す回**。物だけの回は 5〜15%（`reviews/2026-W40.md`）。

## 取るもの・取らないもの

| 取る | 取らない |
|---|---|
| 同じ場所にいる人の**状況**を並べる（「産科病棟の日常」型） | 人を上下に並べるテーマ（年収・学歴・勤務年数・「〇〇レベル」）。比較になり、侮辱的に読まれうる |
| 「あるある」で笑える小さな行動（店を3回確認する、など） | 実写ふうの人物。**クレイのミニチュア**で作る |
| 関係ない人を1人混ぜる（「ただの通勤」）。全員が当事者だと息苦しい | 画像に描かせた文字。日本語が崩れるので、題とラベルは**後から入れる** |

- 相手の性別を決めない。ふたり組は性別の分からない2体にするか、組み合わせを散らす
- 「進んでいる／遅れている」と読めるラベルを置かない（「3回目」はよいが「まだ1回目」は置かない）
- 絵文字なし

## 版面（1080×1920・1枚・10秒・ズームなし）

- 生成は **2:3（縦）**。`render-labels.js` が全面に敷き、左右のはみ出しを切る（2:3 → 左右 約8% ずつ切れる）
- 上：題の帯（y=170〜345・ベージュ半透明・54px）＋ 問いかけ1行（34px）
- ラベル：白い丸い札・30px・**12字まで**。人形の頭のすぐ上。**y=360〜1480 の中だけ**（上は IG のヘッダー、下はキャプションに隠れる）
- ラベル同士が重なると止まる
- **画面の端まで人形がいる絵は `"fit":"width","top":300`**（幅に合わせて y=300 から置く。左右を切らない）。第1回はこちらで出した

だから生成のプロンプトでは、**人形を縦の真ん中（上から18〜77%）・左右の端を避けて**置かせる。

## 手順

1. テーマと**ラベルの案（10前後）**を先に決める。ラベルに合わせて人形の動きをプロンプトに書く（絵にラベルを後付けしない）
2. ふうかさんが ChatGPT で 2:3 生成 → チャットに貼る
3. Claude が画像を見て、人形ごとに座標を決める（描かれなかった動きのラベルは外す・描かれた面白い動きは足してよい）
4. `render-labels.js` → `build_reel.py one10`
5. カバーは書き出した1枚。曲は IG 側。AI 生成の開示

## @koarasan_genkai から取る「概念」（2026-10-05 プロフィール画面を見て整理・ふうか判断待ち）

動画化・実写の人にはしない（ふうか）。取るのは**仕組み**だけ。

| 向こうのやり方 | 取り方 |
|---|---|
| 固定した3本が**全部同じシリーズ**（世帯年収別 ×3）。プロフィールに来た人が「この型の人」と分かる | ぎっしりが3本になったら、**3本とも固定**して棚にする（ハイライトより先にここ） |
| 題が**「〇〇別 ×× N選」の同じ書式** | 題の書式を固定する。例「〇〇の10分前」「〇〇の日常」 |
| ラベルに**番号**（①世帯年収300万…） | ラベル頭に①②…を付ける。コメントが「③です」の一言で済む |
| **同じ家族が毎回出てくる** | 同じクレイの人形を別の回にも出す（「お店を3回確認」の人がラウンジにもいる）。前回の画像を ChatGPT に添えて頼む |
| 軸が「年収」 | **取らない**（上下に並べる軸）。横に並ぶ軸にする：場所別・時間帯別・Kinda type のタイプ別（診断への導線になる） |
