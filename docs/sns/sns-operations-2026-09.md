## 2. 毎朝の Routine（秘書モード）

`trig_01MM1JdLVzPwVq6YQyR5iSZM`「朝のTODO＆発信ブリーフ」／**毎日 7:00 JST**／通知はプッシュ＋メール。
Notion・Supabase・Vercel を接続済み。

### 出力の構成（固定）

1. 今日やること（最大3つ・チェックボックス）
2. 今日の投稿（下書き済なら本文・キャプションを全文。制作中なら画像がまだ要ると明示）
3. **数字の入力**（← 催促する）
4. **期限のあるTODO**（← 催促する。過去日は「〇日超過」）
5. 発信の間隔（事実のみ）
6. 今日の推奨（1つだけ）

### 催促の線引き（意図的に分けている）

| | |
|---|---|
| **催促する** | 締切のあるTODO、数字の入力 |
| **催促しない** | 発信の間隔（節5） |

4方向から毎朝追われると続かないため。コラムが何日空いたかは事実として出すだけにする。
人格への言及はしない（「だらしない」等）。遅れている事実と次の一手だけ。

### Routine がやらないこと

- SNS への実投稿・予約投稿
- **数字の欄を推測で埋めること**（実測値はふうかさんの報告からしか入らない）
- Notion の既存の文面を書き換えること
- リポジトリへの push

## 5. 画像の作り方（確立した流れ）

```
① Claude がプロンプトを出す（docs/guides/miniature-image-guide.md の9ルール準拠）
② ふうかさんが ChatGPT で生成（9:16）
③ チャットに貼る
④ Claude が文字を載せて返す
⑤ ふうかさんが編集ソフトで動きと音をつけて投稿
```

### 守っていること

- **画像の中に文字を入れない**（画像ガイド ルール7）。生成AIは日本語を崩す。文字は必ず後載せ
- 書体は **Shippori Mincho**（サイトと同じ）、色は `#2E2620`。白抜きにしない
- **下端20%を空ける**（Instagram のUIが重なる）
- 背景が騒がしいカットには `#F5EEE6` を大きくぼかした下地を敷く。帯には見えない
- IG 用画像は **WebP変換不要**（アップロード時に再圧縮される）

### 画像の置き場所

- **私に見せるもの** → チャットに貼る（最速・確実）
- **記録として残すもの** → Notion の投稿ページ
- **リポジトリには置かない**（公開リポジトリのうえ、サイトのビルドに乗る）
